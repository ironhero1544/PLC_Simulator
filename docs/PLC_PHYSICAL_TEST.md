# 물리 부품 실행 검증

2026-10-01에 CSV 검증 없이 실행했다.

재현: `ladder_rewrite_tests --physical-only` 또는
`ctest --test-dir cmake-build-ladder-verified -R ladder_physical --output-on-failure`.

## 검증 결과

- 실제 `CompiledPLCExecutor`의 SET/RST/Y0 출력으로 실린더 왕복 20회.
  Box2D가 감지한 후단/전단 리미트 스위치 값을 X0/X1으로 전달하고,
  전단 감지 시 PLC가 Y0을 해제하여 복귀한다. 총 3,763스캔.
- Y0에 따른 24V 입력 → 솔레노이드 상태 → FRL/밸브/실린더 호스의
  압력 및 배기 경로 계산 → 실린더 위치 계산 → Box2D 센서 감지.
  240Hz 물리 갱신과 10ms PLC 스캔을 따로 진행했다.
- 이동 중 FRL 압력 0 및 호스 분리 시 위치가 유지됨.
- 단일 솔레노이드 밸브 전원 상실 시 스프링 복귀 경로로 실린더가
  위치 0까지 돌아옴.
- 컨베이어 전원 ON 시 실제 Box2D 작업물이 1초에 60 좌표 단위 이송됨.
  전원 OFF 뒤 1초 동안 작업물 위치가 유지됨.
- 컨베이어 양 극성의 모터 활성 상태와 귀환선 단선 시 비활성 상태.
  역극성에 따른 실제 이송 방향 반전은 이번 검사의 범위에 포함하지 않음.
- 타워 램프의 독립 색상 출력, 이중 솔레노이드 밸브의 무전원 상태 기억과
  반대 솔레노이드 입력에 따른 전환.

## 실행 경로와 범위

앱이 사용하던 공압 계산과 Box2D 부품/센서 계산을 공유 함수로 분리했다.
앱과 테스트가 같은 `pneumatic_simulation.cpp`, `box2d_simulation.cpp`,
`component_physics_adapter.cpp`를 호출하며 물리식을 복제하지 않는다.
앱은 기존 화면 범위 정보를 공유 Box2D 함수에 전달한다.

검증은 화면 없이 실행하는 시뮬레이터 내부 장치 테스트다. PLC 출력과
전기 입력의 연결, 감지 상태와 X 입력의 연결은 테스트 하네스가 담당한다.
공압 호스 그래프, 솔레노이드 전기 반응, 이동 및 감지는 실제 부품 코드다.
앱 전체의 전기 배선/IO 매핑, GUI 조작, 별도 고급 물리 엔진 모드,
PC에 연결된 실제 PLC나 장비의 동작을 검증한 것은 아니다.

`ladder_runtime` 및 `ladder_physical` 모두 통과했다.
