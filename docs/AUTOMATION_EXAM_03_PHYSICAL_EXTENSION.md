# 공개문제 3번을 위한 창고 실린더 연동

3번 연속 운전의 금속 적재 위치는 2번(아래층 오른쪽) → 5번(위층 왼쪽)이다.
서보 리프트의 Z 이동만으로는 두 열을 선택할 수 없다. 실제 구성도의
창고실린더 역할을 구현하기 위해 저장창고에 구동 실린더 연결 설정을 추가한다.

- 창고의 정면 미리보기에서 일시정지 후 구동 실린더와 이동 거리를 설정한다.
- 일반 복동 또는 센서 내장 복동 실린더를 선택할 수 있다.
- 실제 실린더 스트로크 비율과 회전·뒤집기 방향에 따라 창고가 이동한다.
- 이미 저장된 공작물은 창고와 함께 이동하고 슬롯 번호와 Z 높이를 유지한다.
- 배선·PLC 프로그램은 기존 실린더 제어와 동일하다. 창고가 가상 입력을 생성하지 않는다.
- 저장 파일은 구동 실린더 ID·이동 거리·정지 기준 위치를 저장한다.
  불러오면 실린더 초기 위치를 기준으로 복원하며 실행 중 이동량을 중복 적용하지 않는다.
- 잘못된 실린더 참조 및 이동 거리는 장면 교체 전에 거부한다.

기존 파일은 구동 실린더 없음으로 읽는다. 이 보완은 실제 적재 시험 전
물리 테스트와 저장/로드 테스트 17/17을 통과했다.

실습에서 선택할 창고 이동 거리는 두 열 간격 70(캔버스 좌표 단위)이다.
이를 실제 장치의 mm 스트로크와 동일한 값으로 해석하지 않는다.
전체 RUN 검증은 [실습 가이드](AUTOMATION_EXAM_03_GUIDE.md)에 기록한다.
