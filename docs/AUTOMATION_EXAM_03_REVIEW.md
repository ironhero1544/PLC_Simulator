## 시험 3번 기준 순서

공작물 감지 → 공급 전진 → 공급 후진 → 가공모터 회전 → 가공 하강 →
3초 지연 → 가공 상승 → 가공모터 정지 → 송출 전진 → 송출 후진 →
컨베이어 구동 → 재질 판별.

비금속: 저장박스 저장 → 컨베이어 정지 → 다음 공작물 확인.

금속: 스토퍼 하강 → 스토퍼 광 센서 감지 → 컨베이어 정지 → 리프트 하강 →
흡착 ON → 창고 위치 확인 → 리프트 저장 높이 이동 → 흡착실린더 전진 →
흡착 OFF → 흡착실린더 후진 → 리프트 원점 복귀 → 스토퍼 상승 →
다음 공작물 확인.

단속은 한 사이클, 금속은 2번 칸, 비금속은 박스다. 금속 수량은 숨긴다.
연속은 매거진의 4개를 처리하고 금속을 2번·5번 칸에 차례로 적재한다.
종료 요청은 현재 공작물을 적재/저장한 뒤 처리하며 두 칸이 채워지면 종료한다.
일시정지는 전 동작을 멈추고 5초 후 시스템을 초기화한다.

1. PDF 12~16쪽과 79~80쪽의 작화·공정·I/O·구성·공압 회로를 대조한다.

7. 공정과 센서 완료 조건을 원문과 행별로 대조해 PLC·HMI를 작성한다.
8. 사전 적재한 4개의 자동 처리와 부가조건을 실제 GUI에서 검증한다.
