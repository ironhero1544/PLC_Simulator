# 1. 부품 배치

## 시작과 배치 파일

PLC Simulator를 실행하고 **실배선 모드**를 선택한다.
운전 상태는 STOP으로 둔다. 실배선 도구줄 오른쪽 **불러오기**에서
`exam03-placement-only.json`을 선택한다. 상단 `프로젝트 → 불러오기`와
실배선 도구줄의 JSON 불러오기는 다르므로 구분한다.

![빈 실배선 화면](../../images/exam03-guide/00-empty.png)

![배치 JSON을 불러온 실제 화면](../../images/exam03-guide/01-placement.png)

그림처럼 제어부·밸브 행·기구부가 보이고 연결선이 없으면 배치 불러오기는 완료다.
HMI 화면도 비어 있어야 한다. 화면 전체가 작게 보일 때는 제어부부터 확대해서 작업한다.

배치 파일에는 부품 39개와 위치·회전·크기·Z 범위·표시 레이어·서보 기계 설정이
들어 있다. 배선은 0개, HMI 위젯은 0개이며 PLC 프로그램은 포함하지 않는다.
전원, 입력·출력 설정은 Sink 입력 / Source 출력이다.
부품 이름 뒤 〔숫자〕는 배치 파일의 부품 ID다. 이름이 같은 밸브와 실린더를
구분할 때 사용하며, 화면 좌표 대신 단자 이름으로 연결한다.

마우스 휠로 확대·축소하고 중간 버튼 드래그로 화면을 이동한다.
부품을 다시 옮길 때는 **선택도구**에서 몸체를 드래그한다.
`R`은 회전, `Shift+R`은 반대 방향 회전이다.

## 배치 관계

제어부는 위쪽에 DC 전원·PLC·서보앰프·광 증폭부·HMI 순으로 둔다.
그 아래는 공압 공급·분배·각 구동 밸브 행이고,
아래쪽 설비는 공급·가공·송출 → 컨베이어 → 스토퍼·흡착·창고 → 저장박스 관계다.
배선 공간을 남겨 두고 센서 몸체로 공작물 이동 경로를 가리지 않는다.
공급부의 네 공작물은 감지 센서 위에 겹쳐 있다.
첫 공작물이 공급되고 실린더가 복귀하면 다음 공작물이 내려오는 중력 공급이다.

배치 파일을 불러왔다면 좌표를 다시 입력할 필요가 없습니다.

[부품별 좌표·Z 설정표 보기](reference-placement.md)

## Z와 표시 레이어

오른쪽 **Z**는 물리 높이, **L**은 그리는 순서다.
Z가 다르면 같은 화면 위치에서도 공작물과 부품이 물리적으로 반응하지 않는다.
L에서 몸체를 뒤로 보내도 Z와 동작 조건은 바뀌지 않는다.
배치 JSON은 그룹과 Z 설정을 보존하므로 처음에는 그대로 사용한다.
광 헤드가 이송 장치를 가리면 L 창에서 해당 광 헤드 그룹의 순서를 확인한다.

리프트〔14〕의 기계 설정은 **60 pulse/rev, 리드 1 mm, 스트로크 100 mm,
최대 속도 100 mm/s, 가속도 200 mm/s²**다.
서보의 펄스 위치와 화면상의 Z 높이는 같은 값이 아니다.
JOG 속도 500/1000/1500 mm/min는 이 조건에서 500/1000/1500 pulse/s에 해당한다.
