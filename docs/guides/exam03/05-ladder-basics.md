# 5. 래더 입력 방법

**프로그래밍 모드**에서 편집 모드(F3)로 전환한다.
접점은 F5, 부정 접점은 F6, 출력 코일은 F7, 응용명령은 F8로 입력한다.
응용명령 입력에는 `MOV K500 D100`처럼 명령과 피연산자를 함께 쓴다.
입력 확정은 Enter다. 네모칸을 선택하고 주소 또는 명령을 입력한다.
END만 있는 상태에서 시작해 아래 회로 순서대로 작성한다.

![빈 프로그램과 선택된 첫 칸](../../images/exam03-guide/15-programming-empty.png)

첫 회로는 빈 행의 첫 칸에서 F5 → `M8002` → Enter로 접점을 넣고,
접점을 확정하면 다음 칸이 선택된다.

![M8002 주소 입력](../../images/exam03-guide/16-contact-entry.png)

![접점 확정 후 다음 칸](../../images/exam03-guide/17-contact.png)

다음 칸에서 F8 → `MOV K500 D100` → Enter로 명령을 넣는다.
이 명령은 행 오른쪽에 배치되고 사이 수평선은 자동 연결된다.

![MOV 명령과 피연산자 입력](../../images/exam03-guide/18-mov-entry.png)

![첫 초기화 회로](../../images/exam03-guide/19-first-rung.png)

상단 **컴파일**을 누르면 아래 상태가 `CONVERTED`로 바뀐다.
전체 회로와 END까지 입력한 뒤 다시 컴파일하고 [시운전](06-checks.md)을 진행한다.

![첫 회로 컴파일 결과](../../images/exam03-guide/20-compile-example.png)

새 행은 Insert로 추가한다.
상승 펄스 접점은 Shift+F7, 하강 펄스 접점은 Shift+F8이다.
F9로 가로선을 추가하고, 병렬 회로의 연결점에서는 Shift+F9로 세로 연결을 추가한다.
회로 명세의 괄호가 바뀌는 곳을 먼저 분기하고, 각 분기를 연결한 뒤
공통 출력 명령을 배치한다. 단순히 모든 접점을 한 줄로 나열하면 안 된다.

아래 명령 목록은 별도 파일 없이 문서 안에 제공하는 회로 명세다.
`LD`는 접점 시작, `INV`는 해당 조건 부정, `ANB`는 조건 블록 직렬,
`ORB`는 조건 블록 병렬이다. INV/ANB/ORB 자체를 출력 코일로 넣지 않는다.
표의 조건식을 보고 접점을 직렬·병렬로 배치하고 마지막 명령을 입력한다.
수식에서 `¬`는 B접점, `∧`는 직렬, `∨`는 병렬,
`↑M`은 상승 펄스 접점이다.

먼저 초기화와 HMI 수동 동작, 다음 단계 전환, 다음 서보 명령,
마지막 출력과 초기화 완료 회로를 작성한다.
실제 배치 순서는 아래 회로 표와 동일하게 유지한다.
D10은 다음 단계, D11은 현재 스캔 단계다.
스캔 처음에 D10→D11을 복사해 한 스캔에서 여러 단계를 연달아 통과하지 않게 한다.
