# 3. 제어 배선

> **목표:** 센서 입력·구동 출력과 공압·광 연결을 마칩니다.
> **완료 기준:** 제어 연결 65개, 전원까지 합쳐 116개.

## PLC 입력 X

실린더의 완료 센서, 광 증폭부 출력, 용량형·유도형 신호를 PLC X에 연결한다.
센서 출력 모드는 PNP, PLC 입력은 Sink로 맞춘다.
배치 JSON의 설정을 그대로 사용하면 된다.
PLC X/Y 주소는 8진수이므로 X7 다음은 X10, X17 다음은 X20이다.
X20~X22까지 사용하는 PLC 입력 행이 있는 버전을 사용한다.

각 신호를 입력 행 위의 통로로 올린 뒤 목적 X 핀에 내린다.
센서 전원과 신호를 혼동하지 않도록 핀을 확대해서 연결한다.

송출 감지 증폭부〔43〕의 SIG에서 시작해 제어부 아래 통로로 이동하고,
PLC〔0〕의 X23으로 연결한다. 사진의 목적지 툴팁 `Role: X23`을 확인한다.
이 PLC에서는 입력 세 번째 행의 네 번째 핀이다.

## PLC 출력 Y

출력은 Source로 사용한다. Y 핀에서 목적 코일 + 또는 제어 핀으로 연결한다.
복솔레노이드의 A/B 코일은 각기 다른 Y에 연결한다.
Y17은 운전 공압 공급과 서보 SON 두 곳으로 분기한다.
Y7은 두 컨베이어 구동 핀으로 분기한다.
모터 제어는 가공실린더에 내장된 MOTOR 핀을 사용한다.

예를 들어 Y1에서 시작해 PLC와 밸브 행 사이 통로에 꺾임점 두 개를 만들고,
공급 밸브〔30〕의 빨간 코일 + 핀에 연결한다.
목적지 툴팁은 `SOL_A_24V`여야 한다. 바로 아래 검정 `SOL_A_0V`와
혼동하면 안 된다. 핀이 붙어 보이면 확대하고, 잘못 연결했으면 Ctrl+Z로 취소한다.
코일 0V 연결도 2-3 표에 따라 별도로 만든다.

## 공압 배관

FRL〔5〕의 압력은 0.5 MPa에 해당하는 설정값 5다.
운전 공압 공급 밸브〔6〕를 거쳐 분배기〔7〕로 공급한다.
단솔 공급 밸브의 B 포트를 분배기에 연결하는 것은 이 모델의 운전 ON 상태에서
압력이 나오는 포트를 사용하기 때문이다.
가공·스토퍼·흡착·창고 밸브는 아래 표처럼 실린더 A/B와 교차한다.
외형의 왼쪽/오른쪽만 보고 연결하지 말고 표의 단자 이름대로 연결한다.

진공 분기는 공급 차단 밸브 **앞의 FRL**에서 받는다.
흡착 중 일시정지했을 때 공작물을 유지하려면 이 분기 위치를 지켜야 한다.
별도 진공흡착패드는 추가하지 않는다. 리프트 일체형 실린더의 VAC를 사용한다.

첫 배관은 FRL〔5〕의 아래 OUT에서 시작한다. 밸브 행 아래쪽으로 내려가
수평 이동한 뒤 운전 공압 공급 밸브〔6〕의 아래 P_IN에 연결한다.
전기 배선 때와 동일한 **배선** 도구를 사용한다.

## 광 케이블

증폭부 TX는 송신 헤드, RX는 수신 헤드로 연결한다.
헤드 자체를 PLC X에 연결하지 않는다. PLC는 증폭부의 SIG를 읽는다.
두 헤드는 같은 Z에서 마주 보고, 공작물이 두 헤드 사이를 지나가야 한다.
SIG 배선만 있고 광 케이블이 빠지면 감지하지 않는다.

| 순서 | 출발 단자 | 도착 단자 |
| --- | --- | --- |
| 1 | 송출 감지〔43〕 · **TX** | 송출 공작물 TX〔44〕 · **24V** |
| 2 | 송출 감지〔43〕 · **RX** | 송출 공작물 RX〔45〕 · **24V** |
| 3 | 스토퍼 감지〔46〕 · **TX** | 스토퍼 TX〔47〕 · **24V** |
| 4 | 스토퍼 감지〔46〕 · **RX** | 스토퍼 RX〔48〕 · **24V** |

## 배선 완료 확인

1. 표의 각 줄을 체크한다. HMI 전원선 두 개를 제외한 연결은 총 116개다.
2. 공급·송출·흡착·창고의 FWD/REV와 스토퍼 DOWN/UP을 구분한다.
3. 서보 PULSE=Y0, DIR=Y4, INP=X17, SON=Y17을 확인한다.
4. 흡착 확인=X20, 스토퍼 상승=X21, 박스 통과=X22를 확인한다.
5. `배선 임베딩`을 쓸 경우 표의 태그 이름과 실제 연결을 먼저 확인한다.
   이 가이드에서는 처음에 직접 배선을 유지해 연결을 추적한다.
6. 본인이 만든 진행 상태는 실배선 **저장**으로 별도 이름에 저장한다.
   제공된 배치 JSON 위에 덮어쓰지 않는다.

## 제어 배선 완료 참고 사진

3장의 **제어·공압·광 연결 65개**를 표시한 상태다.
PLC X/Y 연결은 회색, 공압은 파랑, 광 케이블은 보라로 보인다.
이 단계에서는 제어·공압·광 배선을 확인한다.
실제로 만든 회로에는 앞 단계의 전원·동력 배선 51개도 함께 있어야 한다.
전원·동력 배선과 합하면 총 116개다. 모든 배선을 마친 뒤 운전을 시작한다.
