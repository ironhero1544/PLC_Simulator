# 6. 排出と終了

**動作の流れ**

ワーク処理完了 → 数量・終了条件確認 → 停止または次のワーク

> **目標**
> 非金属はボックス通過センサーのON→OFFを待ちます。
> 終了ボタンは現在のワーク完了後の停止を予約します。

```mermaid
flowchart TD
  A[非金属段階30] --> B[X22 ON・ボックス入口通過開始]
  B --> C[段階32でX22 OFFを待つ]
  C --> D[段階31・排出完了]
  E[金属格納完了・段階20] --> F[連続ならD101を増加]
  F --> G{単サイクル・終了予約・金属2個・供給なしのいずれか?}
  D --> G
  G -->|はい| H[M201・M200を解除]
  G -->|いいえ| I[段階0・次のワーク]
```

![ボックス通過と終了分岐の実際のラダー](../../images/exam03-guide/30-ladder-box-finish.png)

<a id="이렇게-그리세요"></a>

### 作成方法

1. D11=30の後のX22 a接点で段階32に入ります。
2. D11=32の後のX22 b接点で段階31に入ります。
3. 終了条件は並列分岐です。
4. 写真のように経路を下の行へ分け、右の共通RST M201へまとめます。
5. すべてを直列にすると、全条件が同時にONでなければ停止しない誤回路になります。

<a id="완료-확인"></a>

### 確認

 終了M112はM203をSETします。ボタンでM201を直接解除して
即時中断しません。連続では金属格納完了ごとにD101を1回増やします。
