# 1. 초기화

**동작 흐름**

첫 스캔 → 숫자·상태 초기화 → 기구 복귀 → 운전 준비

> **목표**
> RUN을 시작한 첫 스캔에 속도 500, 단계 0, 적재 수량 0을 넣고,
> 이전 운전 상태를 해제한 뒤 초기화 상태 M205를 켠다.

```mermaid
flowchart LR
  A[RUN 첫 스캔 M8002] --> B[속도 500 · 단계 0 · 수량 0]
  B --> C[연속 M200 · 운전 M201 해제]
  C --> D[초기화 M205 시작]
  D --> E[실린더 복귀와 서보 원점 확인]
  E --> F[초기화 해제 · 운전 준비]
```

![초기화와 기본 속도 실제 래더](../../images/exam03-guide/24-ladder-init-speed.png)

### 이렇게 그리세요

1. M8002 A접점을 왼쪽에 넣고, 오른쪽 명령을 각 행에 하나씩 배치한다.
2. `MOV K500 D100`, `MOV K0 D10`, `MOV K0 D101`, `RST M200`, `RST M201`, `SET M205` 순이다.
3. 사진의 M8002가 반복되는 이유는 같은 첫 스캔 조건으로 여러 값을 초기화하기 때문이다.

### 완료 확인

 D10=0, D101=0이더라도 모든 축이 원점이라는 뜻은 아니다.
M205는 각 복귀 센서와 서보 위치를 확인한 뒤 해제해야 한다.
