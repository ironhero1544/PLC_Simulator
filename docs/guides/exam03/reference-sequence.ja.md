# 段階・サーボ・復帰条件の参考

供給前進X0 → 後退X1 → モーター始動段階33 → 加工下降X4 → 3秒T0 →
加工上昇X5 → 送出前進X2 → 後退X3 → コンベヤー → 材質X14/X15の順です。
加工モーターは上昇完了までオンにし、送出へ進むときに停止します。

金属はストッパー下降X6と定位置の光検出X16を両方確認してからコンベヤーを止めます。
リフト下降完了はBUSY OFFとINP ONで確認します。
真空ON後、X20がオンになってから倉庫選択へ進みます。
倉庫後退X13または前進X12を確認してから格納高さへ移動します。
シリンダー前進X10 → 真空OFF/X20 OFF → 後退X11 → リフト原点 →
ストッパー上昇X21で完了します。

非金属はボックス通過X22がONになり、その後OFFになったら搬送を終えます。
固定16秒タイマーを格納完了条件には使いません。
4つのワークは非金属→金属→非金属→金属の順です。
金属2個を先に入れると、両格納先が満杯になって終了するため、残りの非金属が未処理になる場合があります。

<a id="서보와-원점"></a>

## サーボと原点

`DDRVA 位置 速度 Y0 Y4` は絶対位置命令です。
`DPLSV D200 Y0 Y4` は上昇JOG、`DPLSV D202 Y0 Y4` は負の速度の下降JOGです。
自動・原点復帰・初期化では、吸着後退X11を確認してからリフトを動かします。
原点完了は `D8340=0`、`X17=ON`、`M8340=OFF` をすべて確認します。
INPだけでは、前の位置の完了を次の動作完了と誤認する場合があります。
原点復帰後に手動JOGしていても、開始段階で絶対0へ戻ってから供給します。

倉庫スロットは正面基準で下段1/2、中段3/4、上段5/6です。
最初の金属は倉庫後退位置の2番、2つ目は前進位置の5番へ格納します。
位置パルスと倉庫Z範囲は、配置ファイルと回路表を1組として使います。
機械設定やZ範囲を変えた場合は、格納パルスも再検証します。

<a id="일시정지와-재시작"></a>

## 一時停止と再開始

M113→M204で一時停止し、T3 K50（5秒）後にM205初期化へ進みます。
一時停止中のY17 OFFで運転空圧とSONを遮断します。
吸着中は真空を保持します。5秒後、供給・送出・吸着・倉庫を後退させ、
加工・ストッパーを上昇させ、サーボを原点復帰させます。
初期化は各後退・上昇センサー、サーボ位置0・INP・BUSY、T13を確認してから解除します。
全出力コイルをOFFにするだけでは、ダブルソレノイドの停止を実現できません。
