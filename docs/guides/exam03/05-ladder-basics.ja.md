# 5. ラダーの入力方法

**プログラミング** で編集（F3）に切り替えます。
接点はF5、反転接点はF6、コイルはF7、応用命令はF8です。
応用命令は `MOV K500 D100` のように命令とオペランドを一緒に入力します。
Enterで確定します。四角のセルを選び、アドレスや命令を入力します。
ENDだけの状態から、以下の回路順に作成します。

![空のプログラムと選択した最初のセル](../../images/exam03-guide/15-programming-empty.png)

空の行の最初のセルでF5 → `M8002` → Enterと操作し、接点を入れます。
接点を確定すると次のセルが選択されます。

![M8002のアドレス入力](../../images/exam03-guide/16-contact-entry.png)

![接点確定後の次のセル](../../images/exam03-guide/17-contact.png)

次のセルでF8 → `MOV K500 D100` → Enterと操作します。
命令は行の右に配置され、間の横線は自動的につながります。

![MOV命令とオペランドの入力](../../images/exam03-guide/18-mov-entry.png)

![最初の初期化回路](../../images/exam03-guide/19-first-rung.png)

上部の **コンパイル** を押すと、下の状態が `CONVERTED` になります。
全回路とENDを入力したら再コンパイルし、[試運転](06-checks.ja.md) へ進みます。

![最初の回路のコンパイル結果](../../images/exam03-guide/20-compile-example.png)

新しい行はInsertで追加します。
立ち上がりパルス接点はShift+F7、立ち下がりはShift+F8です。
F9で横線、並列回路の接続点ではShift+F9で縦接続を追加します。
仕様の括弧が分かれる場所で先に分岐し、各分岐を接続してから、
共通の出力を配置します。すべての接点を1行に並べるだけではありません。

以下の命令一覧は、別ファイルではなく文書内の回路仕様です。
`LD` は接点開始、`INV` は条件反転、`ANB` は条件ブロックの直列、
`ORB` は並列です。INV/ANB/ORB自体を出力コイルとして入力しません。
表の条件式から接点を直列・並列に配置し、最後の命令を入力します。
式の `¬` はb接点、`∧` は直列、`∨` は並列、
`↑M` は立ち上がりパルス接点です。

最初に初期化・HMI手動動作、次に段階移行、サーボ命令、
最後に出力と初期化完了回路を作ります。
実際の回路順も下の表と同じにします。
D10は次の段階、D11は現在スキャンの段階です。
スキャン先頭でD10→D11をコピーし、1スキャンで複数段階を続けて通過しないようにします。
