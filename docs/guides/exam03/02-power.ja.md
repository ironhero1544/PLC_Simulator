# 2. 電源配線

> **目標：** センサー・コイルの電源とサーボ動力の接続を完了します。
> **接続数：** 電源・動力51本。

<a id="배선-도구와-직각-경로"></a>

## 配線ツールと直角経路

**配線** を選び、開始ピン → 空白部分の曲げ点 → 終点ピンの順にクリックします。
空白部分のクリックで経由点を追加します。右クリックは接続中の取り消しです。
ピンの種類で電気・空圧・光の接続が自動的に決まります。
本体の中央を横切らず、部品の列の間の空白に配線を通します。

24Vは赤、0Vは黒、PLC制御線は橙、空圧は青、
光ケーブルは紫にすると追跡しやすくなります。
接続後に線を選び、色と経由点を整理します。
異なる信号を同じ線にまとめません。
分岐に見える線の交差だけで電気的に接続されたとは判断しません。
表にある開始・終点ピンを実際に接続します。

<a id="실제-클릭-예-dc-24v--송출-감지-증폭부-24v"></a>

### 操作例：DC 24V → 送出検出アンプ24V

1. **配線** を選び、DC電源〔1〕の赤い **24V** をクリックします。
2. 電源の上の空白をクリックし、最初の曲げ点を作ります。

![開始ピンから最初の曲げ点まで](../../images/exam03-guide/02-wire-waypoint.png)

3. 送出検出アンプ〔43〕の上の空白をクリックし、横の経路を作ります。

![部品の上に横方向の経路を配置](../../images/exam03-guide/03-wire-route.png)

4. アンプ右側の **24V** をクリックして接続を完了します。
   マウスを重ね、`Role: POWER_24V`、`方向：入力` を確認します。
   SIGと0Vは別のピンなので、この電源線にはつなぎません。

![アンプ24Vへの接続完了](../../images/exam03-guide/04-24v-connected.png)

写真の線は既定の橙色で作成されています。接続後に色を整理します。
ピンの横に「互換性がありません」と出たら、端子を再確認します。
その文字だけで接続完了と判断せず、終点に固定された線を確認します。

<a id="0v-공통"></a>

## 0V共通

DC電源〔1〕の黒い0Vからそれぞれ接続します。
24Vの経路より1マス下に別経路を置きます。
サーボP-COMは0V共通、PEは保護接地です。同じピンとして扱いません。

24Vの例と同じアンプ〔43〕に0Vを接続します。終点のツールチップは
`POWER_0V` です。写真では0Vが青で表示されています。
電気と空圧は線の色だけでなく、ピンの種類で確認します。

## サーボAC電源

AC電源〔4〕とサーボアンプ〔3〕のL1/L2/L3/PEを名前どおりに接続します。
24Vセンサー電源とAC端子を混同しません。この配線はシミュレーターモデルに従います。

| 順序 | 開始端子 | 終点端子 |
| --- | --- | --- |
| 1 | AC電源〔4〕 · **L1** | サーボアンプ〔3〕 · **L1** |
| 2 | AC電源〔4〕 · **L2** | サーボアンプ〔3〕 · **L2** |
| 3 | AC電源〔4〕 · **L3** | サーボアンプ〔3〕 · **L3** |
| 4 | AC電源〔4〕 · **PE** | サーボアンプ〔3〕 · **PE** |

<a id="서보-동력피드백"></a>

## サーボ動力・フィードバック

サーボアンプ〔3〕からリフト・吸着〔14〕のU/V/W/PE/ENCへ接続します。
これはU/V/Wサーボで、A+/A-/B+/B-のステッピングモーターモデルとは異なります。
リフト上部のモーター端子とシリンダーのセンサー端子を区別します。

| 順序 | 開始端子 | 終点端子 |
| --- | --- | --- |
| 1 | サーボアンプ〔3〕 · **U** | リフト · 吸着〔14〕 · **U** |
| 2 | サーボアンプ〔3〕 · **V** | リフト · 吸着〔14〕 · **V** |
| 3 | サーボアンプ〔3〕 · **W** | リフト · 吸着〔14〕 · **W** |
| 4 | サーボアンプ〔3〕 · **PE** | リフト · 吸着〔14〕 · **PE** |
| 5 | サーボアンプ〔3〕 · **ENC** | リフト · 吸着〔14〕 · **ENC** |

<a id="hmi-연결"></a>

## HMIの接続

HMI通信はPLCに自動接続されます。DC電源〔1〕の24V・0VをHMIの24V・0Vへそれぞれ接続します。この2本は上の51本に別途追加します。
HMIボタンはMに書き込み、数値表示はDを読むように編集します。
