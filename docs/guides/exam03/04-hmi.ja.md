# 4. HMI画面の作成

**選択ツール** でHMIをダブルクリック → **画面編集** を開きます。
**HMI操作** の編集ボタンからも開けます。

![HMIダブルクリックメニュー](../../images/exam03-guide/08-hmi-menu.png)

![空のHMI画面エディター](../../images/exam03-guide/09-hmi-editor.png)

編集中はシミュレーションが一時停止し、閉じると編集前の運転状態に戻ります。
画面は288×216、4:3にします。
最初の画面を `テスト動作`、2つ目を `設備試運転` とします。
各ウィジェットの種類・アドレス・位置・サイズは下の表どおりに入力します。
座標とサイズはHMI内部の値で、プログラムのキャンバス座標とは異なります。
ボタンは瞬時動作にします。特にJOGのM104/M105は押している間だけONにします。
切り替えは **画面切替ボタン** をチェックし、**切替先画面** を選びます。
この状態ではPLCアドレス欄の代わりに画面選択欄が表示されます。

<a id="버튼-한-개를-만드는-순서"></a>

### ボタンを1個作る手順

1. **＋ボタン** を押すと、プレビューと一覧にボタンができます。
2. 選択すると右側に表示名・PLCアドレス・位置・サイズが出ます。

![新しいボタンのプロパティ](../../images/exam03-guide/10-hmi-button.png)

3. **表示名** を `倉庫前進`、**PLCアドレス** を `M100` にします。
   既存の文字はCtrl+Aで選択して置き換えます。
4. **モーメンタリボタン**（押している間だけオン） をチェックします。
5. 下の完成設定表どおりに位置・サイズを入力します。写真は既定の位置で
   名前を入力する例なので、最終座標は表に従います。

![表示名と瞬時動作の設定](../../images/exam03-guide/11-hmi-button-name.png)

<a id="두-번째-화면과-전환-버튼"></a>

### 2つ目の画面と切り替えボタン

1. **画面追加** を押すと `Screen 2` ができます。
2. **画面名** を `設備試運転` に変えます。

![2つ目の画面追加](../../images/exam03-guide/12-hmi-page.png)

3. 2つ目の画面にボタンを追加し、**画面切替ボタン** をチェックします。

![画面切替ボタンのプロパティ](../../images/exam03-guide/13-hmi-transition.png)

4. **切替先画面** を `テスト動作` にします。表示名は
   `<- テスト動作` とし、位置・サイズは下の表に従います。
   最初の画面の切り替えボタンは逆に `設備試運転` を対象にします。

![テスト動作画面への切り替え指定](../../images/exam03-guide/14-hmi-transition-target.png)

5. 設定後、左下の **画面を適用** を押します。
   キャンセルすると編集は適用されません。
6. 数値・表示灯・状態メッセージも追加ボタンで作り、下の表の
   アドレス・表示条件を指定します。再編集も同じメニューで開きます。

金属格納数の表示条件には必ず `M210` を設定します。
単サイクルではM210=OFFなので数量を非表示にし、連続では表示します。
原点ランプM209とサーボ動作ランプM211の点滅はPLCプログラムが作ります。
HMIメッセージウィジェットに3つの状態文字列を直接入力します。
