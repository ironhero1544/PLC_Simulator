# 6. コンパイルと試運転

1. プログラミングで **コンパイル** します。エラーは該当回路の命令・オペランドを確認します。
2. 実配線に戻って **実行** を押し、初期化後にHMI操作を開きます。
3. 低・中・高速表示、押している間のJOG、原点の点滅→点灯、モーター5秒、
   倉庫の前進・後退をまず個別に確認します。
4. 原点へ戻り、単サイクルで非金属1個がボックスへ行くか確認します。
5. 金属の単サイクルでは2番スロットへの格納と数量の非表示を確認します。
6. 4つのワークを供給部へ積み直し、連続運転します。
   金属は2→5、非金属2個はボックスへ入り、途中で手動再投入せず完了する必要があります。
7. 終了は直ちに工程を切らず、現在のワークを格納してから停止するか確認します。
8. 吸着後の移動中に一時停止し、5秒後の初期化とその後の再開始を確認します。

| 停止位置 | 最初に確認する接続・条件 |
| --- | --- |
| 供給待機 | X7、供給後退X1、重力供給のZ、原点D8340=0 |
| 加工後 | X4/X5、T0、上昇完了まで加工モーターがONか |
| ストッパー | X6とX16、ストッパーA/B、光TX/RX |
| 吸着直後 | VAC配管、X20、X11、サーボU/V/W/ENC・SON |
| リフト移動 | DDRVA条件、M8340 OFFとX17 ON、目標絶対位置 |
| 倉庫前進・後退 | Y15/Y16、コイル共通、A/B交差接続、X12/X13 |
| 非金属ボックス | X22 ON→OFF、ボックス・ワークのZ、コンベヤーY7 |
| 初期化が解除されない | X1/X3/X5/X11/X13/X21、T13、原点・INP・BUSY |
