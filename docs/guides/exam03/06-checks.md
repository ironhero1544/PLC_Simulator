# 6. 컴파일과 시운전 확인

1. 프로그래밍 모드에서 **컴파일**한다. 오류가 있으면 해당 회로의 명령과 피연산자를 확인한다.
2. 실배선 모드로 돌아가 **시작**을 누른다. 초기화 완료 후 HMI조작을 연다.
3. 저속/중속/고속 표시, 누르는 동안 JOG, 원점 점멸→점등, 모터 5초,
   창고 전진/후진부터 각각 확인한다.
4. 원점으로 돌아온 뒤 단속으로 비금속 1개가 박스에 가는지 확인한다.
5. 금속 단속은 2번 창고 적재와 수량 표시 숨김을 확인한다.
6. 네 공작물을 다시 공급부에 적재하고 연속을 실행한다.
   금속은 2→5, 비금속은 박스에 2개, 중간 수동 재투입 없이 완료되어야 한다.
7. 종료 버튼은 즉시 공정을 끊지 않고 현재 공작물 적재 후 정지하는지 확인한다.
8. 흡착 후 이동 중 일시정지, 5초 후 초기화와 이후 재시작을 확인한다.

| 멈춘 위치 | 먼저 확인할 연결/조건 |
| --- | --- |
| 공급 대기 | X7, 공급 후진 X1, 중력 공급의 Z, 원점 D8340=0 |
| 가공 후 | X4/X5, T0, 가공 모터가 상승 완료까지 켜졌는지 |
| 스토퍼 | X6와 X16, 스토퍼 A/B, 광 TX/RX |
| 흡착 직후 | VAC 배관, X20, X11, 서보 U/V/W/ENC·SON |
| 리프트 이동 | DDRVA 조건, M8340 OFF와 X17 ON, 목표 절대 위치 |
| 창고 전진/후진 | Y15/Y16, 코일 공통, A/B 교차, X12/X13 |
| 비금속 박스 | X22 ON→OFF, 박스와 공작물 Z, 컨베이어 Y7 |
| 초기화 해제 안 됨 | X1/X3/X5/X11/X13/X21, T13, 원점·INP·BUSY |
