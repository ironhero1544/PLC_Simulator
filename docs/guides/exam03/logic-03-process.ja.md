# 3. 供給と加工

**動作の流れ**

供給 → モーター始動 → 下降確認 → 3秒 → 上昇確認 → 送出

> **目標**
> 供給前進・復帰後に加工モーターを始動します。加工下降の
> センサーX4を確認して3秒待ち、上昇させます。上昇完了X5の後に送出します。

```mermaid
flowchart LR
  A[供給前進・X0確認] --> B[供給復帰・X1確認]
  B --> C[先にモーター始動・段階33]
  C --> D[加工下降・X4確認]
  D --> E[T0 K30・3秒待機]
  E --> F[加工上昇・X5確認]
  F --> G[送出前進X2・復帰X3]
  G --> H[コンベヤー搬送]
```

![供給・加工・送出の実際のラダー](../../images/exam03-guide/27-ladder-feed-process.png)

<a id="이렇게-그리세요"></a>

### 作成方法

1. 左に段階比較 `= D11 K段階` を置き、完了センサーとM204/M205のb接点を直列にします。
2. 右の `MOV K次段階 D10` で次の段階を指定します。
3. 例えばD11=3でX4がONなら、D10に4を入れます。
4. D11=4・一時停止OFFでT0 K30を実行し、D11=4・T0完了でD10に5を入れます。

<a id="단계가-바뀌면-무엇이-움직이나요"></a>

### 段階が変わると何が動くか

 MOV K5 D10自体がシリンダーを上げるわけではありません。
後の出力回路が段階に応じてY5/Y6をオンにします。
M8000→MOV D10 D11はスキャン先頭で1回実行し、1スキャンで複数段階を
続けて通過しないようにします。

<a id="완료-확인"></a>

### 確認

 X4を待たずにタイマーを始めると、実際の加工時間が短くなります。
X5がONになる前にモーターを停止したり送出したりしません。
