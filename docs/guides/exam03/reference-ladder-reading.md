# 래더를 읽는 방법

논리도에서 동작 순서를 읽고 래더의 접점과 명령을 확인한다.
입력 방법은 [접점·MOV 예제](05-ladder-basics.md), 전체 조건은 [회로 입력표](reference-program.md)를 참고한다.

래더는 **왼쪽 조건이 모두 성립하면 오른쪽 명령을 실행한다**고 읽는다.
접점이 직렬이면 ‘그리고’, 병렬이면 ‘또는’, 사선이 있으면 ‘OFF일 때’다.
사진의 왼쪽 행 번호는 병렬 분기까지 포함하므로 부록의 회로 번호와 다를 수 있다.
행 번호보다 접점 주소와 오른쪽 명령으로 대응시킨다.

`X`는 센서 입력, `Y`는 구동 출력, `M`은 내부 상태, `D`는 숫자 저장,
`T`는 타이머다. `SET`은 상태를 기억하고 `RST`는 해제한다.
`MOV`는 값을 복사하고 `DMOV`는 32비트 값을 복사한다.
`K`가 붙은 값은 상수이며, 이 예제의 T0/T3는 0.1초 단위다.

| 그림 | 읽는 뜻 |
| --- | --- |
| 접점 직렬 | 조건이 모두 맞아야 실행 |
| 접점 병렬 | 어느 한 조건만 맞아도 실행 |
| 사선 접점 | 해당 신호가 OFF일 때 통과 |
| 오른쪽 코일·명령 | 조건이 맞으면 수행할 동작 |
