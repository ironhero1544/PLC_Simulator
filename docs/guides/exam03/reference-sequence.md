# 단계·서보·복귀 조건 참고

공급 전진 X0 → 후진 X1 → 모터 기동 단계 33 → 가공 하강 X4 → 3초 T0 →
가공 상승 X5 → 송출 전진 X2 → 후진 X3 → 컨베이어 → 재질 X14/X15 순서다.
가공 모터는 상승 완료 전까지 켜 두고, 송출로 넘어갈 때 정지한다.

금속은 스토퍼 하강 X6와 정위치 광 X16을 모두 확인한 후 컨베이어를 멈춘다.
리프트 하강 완료는 BUSY OFF와 INP ON을 확인한다.
진공 ON 후 X20이 켜져야 창고 선택으로 진행한다.
창고 후진 X13 또는 전진 X12 확인 후 적재 높이로 이동한다.
실린더 전진 X10 → 진공 OFF/X20 OFF → 후진 X11 → 리프트 원점 →
스토퍼 상승 X21로 완료한다.

비금속은 박스 통과 X22가 ON된 뒤 다시 OFF될 때 이송을 끝낸다.
고정 16초 타이머를 저장 완료 조건으로 사용하지 않는다.
공작물 네 개의 순서는 비금속→금속→비금속→금속으로 배치되어 있다.
금속 2개를 먼저 넣으면 두 창고가 차는 종료 조건 때문에 나머지 비금속이 남을 수 있다.

## 서보와 원점

`DDRVA 위치 속도 Y0 Y4`는 절대 위치 명령이다.
`DPLSV D200 Y0 Y4`는 상승 JOG, `DPLSV D202 Y0 Y4`는 음수 속도의 하강 JOG다.
자동/원점/초기화 때에는 흡착실린더 후진 X11을 확인한 뒤 리프트를 움직인다.
원점 완료는 `D8340=0`, `X17=ON`, `M8340=OFF`를 모두 확인한다.
INP만 확인하면 이전 위치의 완료 신호를 다음 동작 완료로 오인할 수 있다.
원점 복귀 뒤 수동 JOG를 했더라도 시작 단계에서 절대 0 위치로 복귀한 후 공급한다.

창고 슬롯 번호는 정면 기준 아래층 1/2, 중간층 3/4, 위층 5/6이다.
1개째 금속은 창고 후진 위치의 2번, 2개째는 전진 위치의 5번에 넣는다.
위치 펄스와 창고의 Z 범위는 배치 파일·회로 표를 한 세트로 사용한다.
기계 설정이나 Z 범위를 바꾸면 적재 펄스도 다시 검증해야 한다.

## 일시정지와 재시작

M113→M204로 일시정지하고, T3 K50(5초) 뒤 M205 초기화로 넘어간다.
일시정지 중 Y17을 끄면 운전 공압과 SON이 차단된다.
흡착 중에는 진공을 유지한다. 5초 뒤 공급·송출·흡착·창고 후진,
가공·스토퍼 상승, 서보 원점 복귀를 실행한다.
초기화 완료는 각 후진/상승 센서와 서보 0 위치·INP·BUSY, T13을 확인한 뒤 해제한다.
출력 코일만 전부 OFF하는 것으로 복솔레노이드의 정지를 구현하지 않는다.
