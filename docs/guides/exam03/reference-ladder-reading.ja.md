# ラダーの読み方

論理図で動作順を読み、ラダーの接点と命令を確認します。
入力は [接点・MOV例](05-ladder-basics.ja.md)、全条件は [回路入力表](reference-program.ja.md) を参照してください。

ラダーは **左の条件が成立したら右の命令を実行する** と読みます。
直列は「かつ」、並列は「または」、斜線付きは「OFFのとき」です。
写真の行番号は並列分岐を含むため、付録の回路番号と異なる場合があります。
行番号ではなく、接点アドレスと右の命令で対応させます。

`X` はセンサー入力、`Y` は駆動出力、`M` は内部状態、`D` は数値保存、
`T` はタイマーです。`SET` は状態を保持し、`RST` は解除します。
`MOV` は値、`DMOV` は32ビット値をコピーします。
`K` 付きの値は定数です。この例のT0/T3は0.1秒単位です。

| 図 | 意味 |
| --- | --- |
| 接点の直列 | 全条件が成立すると実行 |
| 接点の並列 | いずれか1つが成立すると実行 |
| 斜線付き接点 | 信号がOFFのときに通る |
| 右のコイル・命令 | 条件成立時に行う動作 |
