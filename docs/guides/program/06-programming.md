# 6. 래더 작성과 편집

래더는 **왼쪽 조건이 성립하면 오른쪽 출력을 수행한다**고 읽습니다.
직렬은 ‘그리고’, 병렬은 ‘또는’, 사선 접점은 ‘OFF일 때 통과’입니다.

## 주소 읽기

| 표기 | 용도 | 예 |
| --- | --- | --- |
| X | 물리 입력 | `X0`: 버튼 또는 센서 |
| Y | 물리 출력 | `Y0`: 램프·밸브·드라이버 |
| M | 내부 상태 | `M100`: HMI 요청, `M200`: 운전 상태 |
| D | 숫자 데이터 | `D100`: 속도 설정값 |
| T / C | 타이머 / 카운터 | 완료 접점과 현재값 사용 |
| K | 10진 상수 | `K10`: 숫자 10 |

X/Y는 8진수 주소입니다. `X7` 다음은 `X10`이며 `X8`로 입력하지 않습니다.
M과 D는 10진수 주소입니다. 화면에 실제 있는 물리 핀 범위와 내부 메모리 주소 범위는 구분합니다.

## 접점 입력

1. **작성(F3)**에서 셀을 클릭합니다.
2. A접점은 `F5`, B접점은 `F6`을 누릅니다.
3. 주소를 입력하고 Enter로 확정합니다.
4. 같은 행의 다음 셀에 다음 조건을 넣으면 직렬 조건이 됩니다.
5. 기존 명령을 선택하고 Enter를 누르면 수정할 수 있습니다.

![X0을 입력한 실제 접점 입력창](../../images/program-guide/basic-contact-input.png)

*F5를 누른 뒤 X0을 입력하고 Enter를 누릅니다.*

## 코일·응용 명령 입력

코일은 빈 셀에서 `F7` → `Y0` → Enter로 입력합니다.
응용 명령은 `F8` → 명령과 피연산자를 공백으로 구분해 입력 → Enter입니다.

예를 들어 `OUT T0 K10`은 1초를 기다리는 타이머입니다.
`OUT`, `T0`, `K10` 사이에 공백을 넣습니다. 자세한 실습은 [1초 뒤 램프 켜기](reference-basic-circuits.md#2-1초-뒤-램프-켜기)에 있습니다.

![OUT T0 K10을 입력한 실제 창](../../images/program-guide/basic-timer-command-input.png)

*F8을 누른 뒤 OUT T0 K10을 입력하고 Enter를 누릅니다.*

![기초 타이머 명령 입력 순서](../../images/program-guide/basic-timer-entry.gif)

*X0 접점 다음에 타이머를 입력한 뒤, 아래 줄에 T0 접점과 Y0 코일을 넣습니다.*

## 상태를 기억할 때

| 명령 | 동작 | 사용할 때 |
| --- | --- | --- |
| OUT 코일 | 매 스캔 조건에 따라 ON/OFF | 버튼 누르는 동안 출력 |
| `SET M200` | 조건이 성립하면 ON 상태 기억 | 자동 운전 시작 |
| `RST M200` | ON 상태 해제 | 정지·초기화 |
| `MOV K100 D100` | 숫자 복사 | 속도·상태값 설정 |

SET에는 해제 조건도 함께 설계합니다. 한 출력 Y를 서로 다른 OUT 코일에서 반복 제어하면
뒤쪽 회로의 결과가 앞쪽 결과를 덮을 수 있으므로 출력 조건을 모아 정리합니다.

## 행·셀·분기 편집

1. `Insert`로 END 앞에 회로를 추가합니다.
2. 셀을 클릭하거나 방향키로 현재 위치를 옮깁니다. 오른쪽 **커서 정보**로 선택 위치를 확인합니다.
3. 여러 셀은 사각형으로 드래그해 선택합니다. 회로 번호 영역은 행 선택에 사용합니다.
4. `Ctrl+C / Ctrl+V`로 선택 영역을 복사·붙여넣습니다.
5. `Delete`로 선택을 지웁니다. END는 마지막의 종료 회로로 유지합니다.
6. 행 번호를 드래그하면 선택한 행 묶음의 순서를 바꿀 수 있습니다.
7. `Ctrl+Z / Ctrl+Y`로 편집을 되돌리거나 다시 적용합니다.

**F9는 가로 연결선**, **Shift+F9는 세로 연결 추가**입니다.
가로 연결선은 이동 길이를 입력하고, 세로 연결은 선택 열에서 아래로 연결할 회로 수를 입력합니다.
세로 연결은 첫 열이나 END에서 추가하지 않습니다. 연결할 아래 회로를 먼저 만들어 둡니다.

병렬 회로는 시작·끝의 연결을 확인합니다. 조건을 다른 줄에 쓰기만 하고 세로 연결하지 않으면
같은 OR 분기가 되지 않습니다. 실제 병렬 회로는 [산업기사 래더 사진](../exam03/logic-02-manual.md)에서 볼 수 있습니다.

## 회로 메모

설명할 회로를 선택하고 백틱 키 `` ` ``로 메모 창을 엽니다.
`공급 전진 완료 → 가공 시작`처럼 조건과 목적을 적으면 큰 프로그램을 다시 읽기 쉽습니다.
메모는 프로젝트와 함께 보관합니다.

## 컴파일

1. 수정 후 **컴파일**을 누릅니다. 작성 모드에서는 `F4`로도 컴파일할 수 있습니다.
2. 실패하면 첫 오류의 명령·주소·피연산자를 확인합니다.
3. 수정한 뒤 다시 컴파일합니다.
4. 성공 상태를 확인하고 **시작**을 누릅니다.

![기초 타이머 회로](../../images/program-guide/basic-timer-complete.png)

*첫 줄은 1초 기다리기, 둘째 줄은 기다림이 끝나면 Y0 켜기입니다.*
