# 10. L 레이어: 표시 순서·그룹·투명도

**L은 화면에 그리는 순서**입니다. 구동부가 다른 부품 뒤에 가려질 때 사용합니다.
숨김·투명도·그룹은 물리 동작이나 전기 연결을 바꾸지 않습니다.

## 창 열기와 선택

1. 부품 목록의 **Z 오른쪽 L** 버튼을 누릅니다.
2. 창을 옮기거나 크기를 늘려 목록을 읽기 편하게 만듭니다.
3. 원하는 부품 행을 클릭합니다.
4. Ctrl+클릭은 선택 추가·해제, Shift+클릭은 범위 선택입니다.
5. 목록 왼쪽 선택 칸을 위아래로 드래그해 여러 행을 선택할 수도 있습니다.
6. 캔버스에서 사각형으로 선택한 여러 부품도 이 창에서 함께 편집합니다.

![L 표시 레이어 창의 순서·불투명도·그룹 항목](../../images/program-guide/04-render-layer.png)

*실제 L 표시 레이어 창의 순서·불투명도·그룹 항목*

목록 위쪽의 부품이 화면 앞에 그려집니다. 그룹 제목은 묶음 이름이며
실제 앞뒤 순서는 부품의 순서와 행을 확인합니다.

## 앞뒤 순서 바꾸기

1. 앞에 보여야 할 부품을 선택합니다.
2. **위로 / 아래로**로 한 단계 이동하거나 **맨 앞으로 / 맨 뒤로**를 사용합니다.
3. 행을 다른 부품 행 앞으로 드래그해 순서를 바꿀 수도 있습니다.
4. 캔버스에서 원하는 동작부와 공작물이 보이는지 확인합니다.

예를 들어 컨베이어 밑에 설치된 광 센서는 컨베이어 뒤로 보내고,
작동을 봐야 할 실린더 로드·공작물은 필요한 순서로 앞에 둡니다.
선택된 여러 부품을 함께 옮기면 그 부품들 사이의 순서는 유지됩니다.

## 그룹 만들기와 한 번에 조절

1. 실린더·솔레노이드·관련 센서를 함께 선택합니다.
2. 그룹 이름에 `공급부`를 입력합니다.
3. **선택 그룹화 / 이름 변경**을 누릅니다.
4. 그룹 제목을 누르면 구성 부품 전체가 선택됩니다.
5. 그룹 전체에 순서·불투명도·숨김을 적용합니다.
6. 선택한 행을 다른 그룹 제목에 드래그하면 그 그룹에 넣을 수 있습니다.
7. **그룹 해제**는 선택된 부품만 그룹에서 꺼냅니다.

같은 그룹 이름을 입력하면 기존 그룹에 합쳐집니다. 그룹은 표시 편집용 묶음입니다.
기계적으로 붙어 함께 움직이는 축이나 부품을 만드는 기능은 아닙니다.

## 투명도와 숨김 복구

**불투명도 100%**는 일반 표시, **0%**는 완전 투명입니다.
숨긴 부품과 0%인 부품은 캔버스에서 클릭되지 않습니다.

1. 부품이 사라졌다면 L 창의 행을 찾습니다.
2. 행을 선택하고 **보이기**를 누릅니다.
3. 불투명도를 100%로 올립니다.
4. 다른 부품 뒤에 있으면 표시 순서도 조절합니다.

![L 창에서 PLC 숨기기·보이기](../../images/program-guide/render-visibility.gif)

*L 창에서 PLC 숨기기·보이기*

숨긴 부품의 연결과 물리 동작은 유지되며 **배선 자체도 표시됩니다**.
선까지 안 보이게 만드는 기능으로 숨김을 사용하지 않습니다.
잘못 편집한 순서·표시는 실행 취소할 수 있고 프로젝트 저장으로 보관합니다.
