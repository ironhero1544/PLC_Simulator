# 8. HMI 조작과 화면 편집

HMI는 **조작창에서 버튼을 사용하는 작업**과 **화면 편집기로 위젯을 만드는 작업**을 나눕니다.
PLC 통신선은 따로 그리지 않습니다. **24V·0V 전원은 연결하고**, 같은 실습에 PLC를 하나 둡니다.
현재 HMI는 PLC가 둘 이상이면 연결 대상을 결정하지 못합니다.

## 조작창 열기와 크기 조절

1. 실배선에서 **선택도구**를 누릅니다.
2. HMI 몸체를 더블클릭합니다.
3. **HMI 조작**을 선택합니다.
4. 창 가장자리 또는 우측 하단을 드래그해 창 크기를 바꿉니다.
5. 놓은 창의 내부 공간에 맞춰 HMI 화면이 **4:3** 비율을 유지하며 표시됩니다.
6. 버튼을 눌러 동작을 확인합니다. 순간 버튼은 누르고 있는 동안만 ON입니다.

![HMI 조작·화면 편집 전용 메뉴](../../images/exam03-guide/08-hmi-menu.png)

*HMI 조작·화면 편집 전용 메뉴*

![HMI 조작창 크기를 늘린 예. 위젯은 산업기사 프로젝트 예시입니다](../../images/automation-exam-03/74-hmi-resize-after.png)

*실제 HMI 조작창 크기를 늘린 예. 위젯은 산업기사 프로젝트 예시입니다*

HMI에서 ‘수평으로 보기’를 찾을 필요가 없습니다. **HMI 조작**이 전용 메뉴입니다.
버튼이 동작하지 않으면 HMI 전원, PLC 한 개, 컴파일 성공, RUN, 편집 일시정지 상태를 확인합니다.

## 화면 편집기 열기

1. HMI 더블클릭 → **화면 편집**을 선택합니다.
2. HMI 조작창의 **화면 편집** 버튼으로 열어도 됩니다.
3. 시뮬레이션 일시정지 안내가 나타나는지 확인합니다.
4. 편집창 가장자리를 드래그해 작업하기 편한 크기로 늘립니다.
5. 왼쪽은 미리보기, 아래는 위젯 목록, 오른쪽은 선택한 위젯의 속성입니다.

![HMI 화면 편집기와 일시정지 안내](../../images/exam03-guide/09-hmi-editor.png)

*실제 HMI 화면 편집기와 일시정지 안내*

화면 좌표는 **288×216**입니다. 편집창을 크게 해도 위젯 좌표 체계는 그대로입니다.
현재 한 HMI는 **최대 8개 화면, 전체 화면을 합쳐 최대 32개 위젯**을 사용합니다.

## 버튼 한 개 만들기

1. 위쪽 **+ 버튼**을 누릅니다.
2. 새 위젯을 선택합니다.
3. 표시 이름을 `운전 요청`, PLC 주소를 `M100`으로 입력합니다.
4. **누르는 동안만 켜짐**을 체크합니다.
5. 미리보기에서 끌어 위치를 맞춥니다. 우측 하단 손잡이로 크기를 조절합니다.
6. 위치·크기 입력칸으로 숫자를 맞추고 5px 격자 맞춤을 이용합니다.
7. **화면 적용**을 누릅니다.
8. 래더에 M100을 읽는 접점을 작성하고 컴파일한 뒤 사용합니다.

![버튼을 선택하면 오른쪽에 속성이 나타납니다](../../images/exam03-guide/10-hmi-button.png)

*버튼을 선택하면 오른쪽에 속성이 나타납니다*

HMI 버튼 주소는 **M 주소**입니다. 서로 다른 조작 버튼에는 서로 다른 M 주소를 씁니다.
여러 화면에 있는 일반 버튼끼리도 같은 M 주소를 중복 지정하면 설정 검증에 걸립니다.
JOG에는 순간 버튼을 사용해 손을 놓으면 요청이 OFF가 되게 합니다.
버튼이 Y를 직접 제어한다고 생각하지 말고 M 요청을 래더가 처리하도록 작성합니다.

![버튼 추가 → 속성 선택 → 이름 변경의 실제 조작 단계. 기존 버튼 때문에 M103을 사용한 예](../../images/program-guide/hmi-button-edit.gif)

*버튼 추가 → 속성 선택 → 이름 변경의 실제 조작 단계. 기존 버튼 때문에 M103을 사용한 예*

## 표시 위젯

| 위젯 | 설정 예 | 역할 |
| --- | --- | --- |
| 표시등 | `M200` 또는 `Y0` | 비트의 ON/OFF 표시 |
| 숫자 표시 | `D100`, 단위 `mm/min` | 숫자 데이터 읽기 |
| 고정 글자 | `자동 운전` | 제목·설명 표시 |
| 상태 메시지 | `D103`에 대응하는 메시지 | 상태 번호별 문구 표시 |

숫자 표시는 현재 **표시용**입니다. 숫자를 클릭해 속도를 쓰는 입력 위젯으로 안내하지 않습니다.
속도 변경은 버튼 M 요청을 받고 래더의 MOV 등으로 D 값을 갱신하는 방식으로 구성할 수 있습니다.
**비트 ON일 때 표시**는 M/X/Y 조건을 지정하고, 항상 보이게 하려면 비웁니다.

## 두 번째 화면과 전환 버튼

1. **화면 추가**를 누릅니다.
2. 화면 이름을 `수동 운전`으로 바꿉니다.
3. 버튼을 추가하고 **화면 전환 버튼**을 체크합니다.
4. **전환할 화면**에서 첫 화면을 선택합니다.
5. 표시 이름을 `<- 자동 운전`으로 입력합니다.
6. 첫 화면에도 `수동 운전 ->` 버튼을 만들고 두 번째 화면을 대상으로 지정합니다.
7. 화면 적용 후 HMI 조작창에서 양방향 전환을 확인합니다.

![화면 전환 버튼의 대상 지정](../../images/exam03-guide/14-hmi-transition-target.png)

*화면 전환 버튼의 대상 지정*

전환 버튼은 화면 대상을 사용하므로 일반 조작 버튼처럼 M 주소를 할당하지 않습니다.
화면 전환도 운전 가능한 HMI 연결 상태에서 확인합니다.

![두 번째 화면 추가와 전환 대상 지정](../../images/program-guide/hmi-screen-switch.gif)

*두 번째 화면 추가와 전환 대상 지정*

## 적용·취소와 저장

**화면 적용**은 편집 내용을 HMI에 적용합니다. **취소**는 이번 편집을 버립니다.
편집창을 닫으면 편집 일시정지가 해제됩니다. 프로젝트 저장은 별도로 해야 파일에 남습니다.
버튼·램프를 복제한 뒤에는 주소와 위치를 다시 확인합니다.
