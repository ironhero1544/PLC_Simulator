# 기본 회로를 한 가지씩 연습하기

아래 표의 **왼쪽 조건**은 접점, **오른쪽 명령**은 코일 또는 응용 명령입니다.
표 한 행을 한 회로로 입력하고 마지막 END를 유지합니다.
각 예는 별도 실습입니다. 같은 Y0를 쓰는 예제를 한 프로그램에 모두 합치지 않습니다.

접점은 F5/F6, 응용 명령은 F8, 입력 확정은 Enter입니다.
기본 OUT은 F7을 이용해도 됩니다. 입력 후 컴파일하고 RUN에서 확인합니다.

배선 없이 래더만 연습한다면 **STOP에서 모니터(F2)**를 열고 오른쪽 X 버튼으로 시험할 수 있습니다.
입력 버튼과 현재값 읽는 방법은 [기초 모니터 실습](07-monitoring.md)에 있습니다.

## 1. 시작·정지를 기억하는 회로

버튼은 누르는 동안만 입력을 만듭니다. 운전 상태를 유지하려면 M에 상태를 기억합니다.
X0는 시작 버튼, X1은 정지 버튼의 **NO 신호**로 가정합니다.
실제 장비의 비상정지 배선 설계와 구분한 시뮬레이터 기초 연습입니다.

| 회로 | 왼쪽 조건 | 오른쪽 명령 |
| --- | --- | --- |
| 1 | X0 A접점 | `SET M200` |
| 2 | X1 A접점 | `RST M200` |
| 3 | M200 A접점 | `OUT Y0` |

1. 첫 회로에서 F5로 X0을 넣고 다음 셀에서 F8로 `SET M200`을 입력합니다.
2. 새 회로에 X1과 `RST M200`을 입력합니다.
3. 마지막 회로에 M200과 Y0 코일을 입력합니다.
4. 컴파일하고 시작합니다.
5. X0를 눌렀다 놓아도 M200·Y0가 켜져 있는지 봅니다.
6. X1을 누르면 꺼지는지 봅니다.

이 배치에서는 같은 스캔에 두 입력이 모두 ON이면 뒤쪽 RST가 상태를 해제합니다.
정지 버튼을 실제 NC 배선으로 바꾸면 X1의 정상·누름 상태가 달라지므로 조건도 다시 작성합니다.

## 2. 1초 뒤 램프 켜기

| 회로 | 왼쪽 조건 | 오른쪽 명령 |
| --- | --- | --- |
| 1 | X0 A접점 | `OUT T0 K10` |
| 2 | T0 A접점 | `OUT Y0` |

1. X0 접점을 입력하고 다음 셀에서 F8 → `OUT T0 K10` → Enter를 입력합니다.
2. 다음 회로에는 T0 접점과 Y0 코일을 입력합니다.
3. 컴파일·시작 후 X0을 누르고 유지합니다.
4. T0 현재값이 10에 도달하면 T0 완료 접점과 Y0가 ON인지 확인합니다.
5. X0을 해제하면 현재값·완료 접점·Y0가 해제되는지 확인합니다.

T0의 K10은 **1초**입니다. 이 실습에서는 T0만 사용하세요.

![기초 타이머 두 줄 회로를 실제 앱에 입력한 화면](../../images/program-guide/basic-timer-complete.png)

첫째 줄: X0 버튼을 누르고 있으면 T0가 시간을 셉니다.
둘째 줄: 1초가 지나면 T0 접점이 켜져 Y0 램프가 켜집니다.
버튼을 놓으면 타이머와 램프가 꺼집니다.

## 3. 세 번 입력하면 램프 켜기

| 회로 | 왼쪽 조건 | 오른쪽 명령 |
| --- | --- | --- |
| 1 | X0 A접점 | `OUT C0 K3` |
| 2 | C0 A접점 | `OUT Y0` |
| 3 | X1 A접점 | `RST C0` |

1. X0와 `OUT C0 K3`을 입력합니다.
2. C0와 Y0를 입력합니다.
3. X1와 `RST C0`을 입력합니다.
4. 컴파일하고 시작한 뒤 X0를 눌렀다 놓는 동작을 세 번 반복합니다.
5. 세 번째에 Y0 램프가 켜집니다. 버튼을 계속 누르고 있으면 한 번만 셉니다.
6. X1을 눌러 C0와 Y0가 해제되는지 봅니다.

![기초 카운터 세 줄 회로를 실제 앱에 입력한 화면](../../images/program-guide/basic-counter-complete.png)

첫째 줄: X0 버튼을 누를 때마다 한 번씩 셉니다.
둘째 줄: 세 번이 되면 Y0 램프가 켜집니다.
셋째 줄: X1 버튼을 누르면 센 횟수가 0으로 돌아가고 램프도 꺼집니다.

## 4. HMI 버튼으로 설정값 바꾸기

HMI 숫자는 표시용이므로 버튼 요청을 래더가 숫자로 바꾸게 만듭니다.

| HMI 위젯 | 주소 | 설정 |
| --- | --- | --- |
| 저속 버튼 | M100 | 순간 동작 |
| 고속 버튼 | M101 | 순간 동작 |
| 속도 숫자 표시 | D100 | 단위는 실습에 맞춰 입력 |

| 회로 | 왼쪽 조건 | 오른쪽 명령 |
| --- | --- | --- |
| 1 | M100 A접점 | `MOV K100 D100` |
| 2 | M101 A접점 | `MOV K500 D100` |

HMI를 적용하고 두 회로를 컴파일합니다. RUN에서 저속·고속 버튼을 누르면
D100 숫자 표시가 각각 100·500으로 바뀌는지 확인합니다.
이 회로만으로 모터 속도가 변하지는 않습니다. 드라이버·PWM 또는 모션 명령이 D100을 사용하도록 따로 연결해야 합니다.

## 5. 조건을 직렬로 확인하기

‘운전 요청 M200이 ON이고, 가공 감지 X2가 ON이고, 정지 요청 M201이 OFF일 때 Y1’은
M200 A접점 → X2 A접점 → M201 B접점 → Y1 코일입니다.

1. 같은 행에 F5 M200, F5 X2, F6 M201 순서로 입력합니다.
2. 마지막에는 F7 Y1을 입력합니다.
3. 모니터에서 조건을 앞에서부터 읽습니다.
4. Y1이 OFF이면 어느 접점에서 조건이 끊기는지 확인합니다.

병렬 분기가 필요한 ‘또는’ 조건은 [래더 편집 장](06-programming.md)의 분기 설명과
[실제 병렬 회로 사진](../exam03/logic-02-manual.md)을 함께 확인합니다.
