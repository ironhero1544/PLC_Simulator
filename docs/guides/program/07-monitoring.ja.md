# 7. モニターでラダー動作を確認

**モニターは、自分のラダーでどの入力・出力がオンになっているかを見る画面です。**
最初はX0だけでY0をオンにする回路を確認します。ONはオン、OFFはオフです。

<a id="1-배선-없이-한-줄-회로-시험하기"></a>

## 1. 配線なしで1行の回路を試す

現在のプロジェクトがある場合は先に保存し、別の実習として進めてください。
この手順では部品や配線なしで **ラダーだけ** を試します。

1. **プログラミング → 編集（F3）** を押します。
2. 左端のセルを選び、**F5 → X0 → Enter** で接点を入れます。
   ENDだけの画面でも、ENDの左端でF5を押すと新しい回路ができます。
3. 次の空セルで **F7 → Y0 → Enter** と操作し、コイルを入れます。
4. **コンパイル** を押します。下に **CONVERTED** が出れば準備完了です。
5. 右上を **STOP** のままにし、**モニター（F2）** を押します。

![X0とY0だけの基本モニター画面](../../images/program-guide/monitor-basic-overview.png)

*左のX0は入力条件、右のY0は出力です。右側の「入力制御」で試すXを押します。*

6. 右側の **入力制御** で **X0** を1回クリックします。
7. X0接点とY0コイルが薄い青になり、右側の **Y0** が赤になります。
8. **X0** をもう一度クリックすると、X0とY0がオフになります。

**右側のXボタンは、1回クリックでオン、もう1回でオフになります。**
押し続ける必要はありません。Yボタンは結果の表示です。
Y0をクリックして出力をオンにする操作ではありません。

![X0のオン・オフに合わせて変わるY0](../../images/program-guide/monitor-basic-toggle.gif)

*同じ画面の接点・コイル・入出力表示を拡大しています。*

<a id="2-화면에서-무엇을-읽어야-하나요"></a>

## 2. 画面の読み方

| 場所 | 読み方 |
| --- | --- |
| 接点・コイルの薄い青の背景 | 条件または出力が有効 |
| 右側の入力Xの緑色 | 入力ON。灰色はOFF |
| 右側の出力Yの赤色 | 出力ON。灰色はOFF |
| 濃い青の枠の四角 | 選択中のセル。クリックや方向キーで移動 |

**選択枠とオン表示は別です。**
X0をオフにしても選択セルの枠は残ります。枠だけでONと判断しないでください。
マウスを重ねるとボタンの色が変わる場合があります。マウスを横へ移して確認します。

![X0がOFFでも残る選択枠](../../images/program-guide/monitor-selection-off.png)

*選択枠はありますが、内側の背景は白です。X0はOFFです。*

右側の一覧が長い場合は **右側のペイン内でスクロール** します。
下の回路を見るには **中央のラダー領域内でスクロール** します。

<a id="3-타이머-값-읽기"></a>

## 3. タイマー値の読み方

[1秒後にランプを点灯](reference-basic-circuits.ja.md#2-1초-뒤-램프-켜기) の2行の回路を入力します。
**コンパイル → モニター（F2）** を押し、右側のX0をオンにします。

右上の **タイマー／カウンター** でT0を確認します。
`T0 K0/10` は **現在値0、目標10** という意味です。
この例のT0は0.1秒単位で数えるため、10になると1秒経過したことになります。

![タイマーの開始前と完了後の値](../../images/program-guide/monitor-timer-values.png)

*開始前は0/10と0%、完了後は10/10と100%です。バーは進行状況を示します。*

1. X0をオンにしておくと、数値と進行バーが増えます。
2. 目標10になると下の行の **T0接点** と **Y0** がオンになります。
3. X0をオフにするとT0が0に戻り、Y0もオフになります。

コイル下の `T0=10 K10=10` も **現在値10、設定値10** を示します。
数値のクリックでは時間を変更できません。編集モードで命令を修正します。

<a id="4-카운터-값-읽기"></a>

## 4. カウンター値の読み方

[3回入力したらランプを点灯](reference-basic-circuits.ja.md#3-세-번-입력하면-램프-켜기) の3行の回路を入力します。
**コンパイル → モニター（F2）** を押します。

1. X0をオンにしてからオフにします。右側のC0が **1/3** になります。
2. もう一度オン・オフにすると **2/3** になります。
3. 3回目のオンで **3/3** になり、**Y0** がオンになります。
4. X0をオフにします。カウンターは回数を保持するためY0はオンのままです。
5. X1をオンにすると **0/3** に初期化されY0がオフになります。X1も再びオフにします。

**X0をオンのままにすると1回しか数えません。** 次を数えるには一度オフにしてからオンにします。

![カウンターの0・1・2・3と初期化](../../images/program-guide/monitor-counter-count.gif)

*現在回数とY0を一緒に見てください。3回でY0がオンになり、X1の初期化でオフになります。*

<a id="5-배선한-버튼센서의-상태-보기"></a>

## 5. 配線済みボタン・センサーの状態を見る

ここまでは右側のXボタンでラダーだけを試しました。
[ボタン・ランプの実配線実習](05-first-practice.ja.md) を作ったら、次の手順で実際の部品を試します。

1. ラダーをコンパイルし、右上の **実行** を押します。**RUN** が表示されます。
2. **配線 → 選択ツール** で配線したボタンを押します。
3. **プログラミング → モニター（F2）** でX0とY0を確認します。
4. この状態では右側のXボタンは無効になります。実配線のボタン・センサーで入力を変えます。

| 表示 | この実習での意味 |
| --- | --- |
| STOP＋モニター（F2） | 右側のXボタンでラダーだけを試験 |
| RUN＋モニター（F2） | 配線済み部品の入出力を観察 |
| 編集（F3） | ラダーの入力・修正 |

ラダーだけの試験では、キャンバス上のランプまで点灯するかは確認しません。
実際のランプは配線を完了してからRUNで確認してください。

<a id="6-수정하고-다시-시험하기"></a>

## 6. 修正して再試験する

1. RUN中なら右上の **停止** を押します。
2. **編集（F3）** を押します。ラダーだけの試験もこのボタンで終了します。
3. 修正する接点・命令を選び、**Enter** を押します。
4. 値を修正してEnterで確定し、**再コンパイル** します。
5. ラダーだけの試験はモニター（F2）、実配線の試験は開始を押します。

<a id="7-반응이-없으면-이-순서로-보기"></a>

## 7. 反応しない場合の確認順

| 症状 | 最初の操作 |
| --- | --- |
| 右側の入力制御が見えない | モニター（F2）を押し、右ペインをスクロール |
| X0ボタンを押しても変わらない | RUNなら実配線のボタンを使う。ラダーだけの試験は停止 |
| X0はONだがY0がOFF | X0・Y0のアドレスと最新回路のコンパイルを確認 |
| T0がずっと0 | X0をONに維持。OUT T0 K10を確認 |
| C0が1回しか増えない | X0を一度オフにしてから再びオン |
| 初期化後に数えない | X1をオフにしてX0を試験 |
| Y0はONだが実際のランプが消灯 | RUNとY0→ランプの配線を確認 |

HMI編集やZウィンドウで一時停止している場合は、編集画面を閉じるか一時停止を解除します。
HMI編集前からSTOPだった場合、閉じても自動でRUNにはなりません。

M・Dを使う回路では、右側にそれらの項目も表示されます。
Mは保持したON/OFF状態、`D100 = 100` はD100に入っている数値です。
最初は上のX0・Y0・T0・C0の実習から覚えてください。
