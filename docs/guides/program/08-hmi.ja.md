# 8. HMI操作と画面編集

HMIでは **操作画面でボタンを使う作業** と **画面エディターでウィジェットを作る作業** を分けます。
PLCとの通信線は描きません。**24V・0Vの電源を接続** し、同じ実習にPLCを1台置きます。
現在のHMIは、PLCが2台以上あると接続先を決定できません。

<a id="조작창-열기와-크기-조절"></a>

## 操作画面を開く・サイズ変更

1. 実配線で **選択ツール** を押します。
2. HMIの本体をダブルクリックします。
3. **HMI操作** を選びます。
4. ウィンドウの端または右下をドラッグしてサイズを変更します。
5. HMI画面は変更後の内側領域に合わせ、**4:3** の比率を保って表示されます。
6. ボタンを押して動作を確認します。瞬時ボタンは押している間だけONです。

![HMI操作・画面編集の専用メニュー](../../images/exam03-guide/08-hmi-menu.png)

*HMI操作・画面編集の専用メニュー*

![HMI操作画面を拡大した例。ウィジェットは産業技師プロジェクトの例です](../../images/automation-exam-03/74-hmi-resize-after.png)

*HMI操作画面を拡大した例。ウィジェットは産業技師プロジェクトの例です*

HMIで「水平表示」を探す必要はありません。専用の **HMI操作** を使います。
ボタンが動かない場合は、HMI電源、PLCが1台か、コンパイル成功、RUN、編集一時停止の状態を確認します。

<a id="화면-편집기-열기"></a>

## 画面エディターを開く

1. HMIをダブルクリック → **画面編集** を選びます。
2. HMI操作画面の **画面編集** ボタンからも開けます。
3. シミュレーション一時停止の案内を確認します。
4. 編集画面の端をドラッグし、作業しやすい大きさにします。
5. 左がプレビュー、下がウィジェット一覧、右が選択ウィジェットのプロパティです。

![HMI画面エディターと一時停止案内](../../images/exam03-guide/09-hmi-editor.png)

*HMI画面エディターと一時停止案内*

画面座標は **288×216** です。エディターを拡大しても座標体系は変わりません。
現在1台のHMIで **最大8画面、全画面合計32ウィジェット** を使用できます。

<a id="버튼-한-개-만들기"></a>

## ボタンを1個作る

1. 上部の **＋ボタン** を押します。
2. 新しいウィジェットを選びます。
3. 表示名を `運転要求`、PLCアドレスを `M100` にします。
4. **モーメンタリボタン**（押している間だけオン） をチェックします。
5. プレビューでドラッグして位置を調整し、右下のハンドルでサイズを変更します。
6. 位置・サイズを数値で調整し、5pxグリッドへのスナップを使います。
7. **画面を適用** を押します。
8. M100を読む接点をラダーに作り、コンパイルしてから使います。

![ボタンを選ぶと右側にプロパティが表示されます](../../images/exam03-guide/10-hmi-button.png)

*ボタンを選ぶと右側にプロパティが表示されます*

HMI操作ボタンには **Mアドレス** を使います。異なるボタンには異なるMを割り当てます。
別の画面でも通常ボタンに同じMを重複させると、設定の検証でエラーになります。
JOGには瞬時ボタンを使い、離したときに要求がOFFになるようにします。
ボタンがYを直接制御するのではなく、M要求をラダーで処理するように作ります。

![ボタン追加・プロパティ選択・名前変更。既存ボタンがあるためM103を使用した例](../../images/program-guide/hmi-button-edit.gif)

*ボタン追加・プロパティ選択・名前変更。既存ボタンがあるためM103を使用した例*

<a id="표시-위젯"></a>

## 表示ウィジェット

| ウィジェット | 設定例 | 役割 |
| --- | --- | --- |
| 表示灯 | `M200` または `Y0` | ビットのON/OFFを表示 |
| 数値表示 | `D100`、単位 `mm/min` | 数値データを読む |
| 固定文字 | `自動運転` | 見出し・説明を表示 |
| 状態メッセージ | `D103` に対応するメッセージ | 状態番号ごとの文字列を表示 |

数値表示は現在 **表示専用** です。数値のクリックでは速度を入力できません。
速度変更はボタンのM要求を受け、ラダーのMOVなどでD値を更新する方式にできます。
**ビットON時に表示** にはM/X/Y条件を指定します。常時表示する場合は空にします。

<a id="두-번째-화면과-전환-버튼"></a>

## 2つ目の画面と切り替えボタン

1. **画面追加** を押します。
2. 画面名を `手動運転` に変えます。
3. ボタンを追加し、**画面切替ボタン** をチェックします。
4. **切替先画面** で最初の画面を選びます。
5. 表示名に `<- 自動運転` を入力します。
6. 最初の画面にも `手動運転 ->` ボタンを作り、2つ目の画面を指定します。
7. 適用後、HMI操作画面で双方向に切り替えられることを確認します。

![画面切替ボタンの対象指定](../../images/exam03-guide/14-hmi-transition-target.png)

*画面切替ボタンの対象指定*

切り替えボタンは画面を対象にするため、通常の操作ボタンのようにMを割り当てません。
画面切り替えも、HMIが接続され操作できる状態で確認します。

![2つ目の画面追加と切り替え先の指定](../../images/program-guide/hmi-screen-switch.gif)

*2つ目の画面追加と切り替え先の指定*

<a id="적용취소와-저장"></a>

## 適用・キャンセル・保存

**画面を適用** は編集をHMIに反映し、**キャンセル** は今回の編集を破棄します。
編集画面を閉じると編集一時停止が解除されます。ファイルに残すには別途プロジェクトを保存します。
ボタン・ランプの複製後はアドレスと位置を再確認します。
