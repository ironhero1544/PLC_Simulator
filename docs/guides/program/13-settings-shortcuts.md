# 13. 설정·단축키·문제 해결

화면이 작거나 글씨가 읽기 어렵다면 캔버스 확대와 UI 설정을 각각 조절합니다.
캔버스 Zoom은 부품을 보는 배율이고, UI 스케일은 메뉴·창 등의 크기입니다.

## 언어와 UI 크기

1. **설정 → 언어**에서 한국어·영어·일본어를 선택합니다.
2. **설정 → UI**를 엽니다.
3. **UI 스케일**로 전체 UI 배율을 조절합니다.
4. **폰트 스케일**로 글씨 크기를 조절합니다.
5. **레이아웃 크기**로 여백·창 구성을 조절합니다.
6. 재시작 안내가 나오면 작업을 저장하고 재시작합니다.
7. 크기를 다시 맞추려면 **기본값으로**를 사용합니다.

![UI 스케일·폰트·레이아웃·프레임 설정 메뉴](../../images/program-guide/05-ui-settings.png)

*실제 UI 스케일·폰트·레이아웃·프레임 설정 메뉴*


UI·폰트·레이아웃 스케일은 현재 0.75~1.5 범위를 사용하며 재시작이 필요한 설정입니다.
**VSync**와 **프레임 제한(모니터)**은 렌더링 관련 설정입니다.
프레임 제한 숫자를 바꾸는 것을 서보 속도나 PLC 타이머 설정으로 생각하지 않습니다.

## 공통 단축키

| 키 | 동작 |
| --- | --- |
| Tab | 실배선 / 프로그래밍 전환 |
| Ctrl+S | 통합 프로젝트 저장 창 |
| Ctrl+, / Ctrl+/ | 도움말 · 사용법 가이드 열기 |
| Ctrl+Z | 실행 취소 |
| Ctrl+Y / Ctrl+Shift+Z | 다시 실행 |

텍스트 입력칸과 팝업을 편집하는 동안에는 같은 키가 입력에 사용되거나 단축키가 제한될 수 있습니다.
단축키가 먹지 않으면 입력창을 확정·닫고 캔버스나 래더를 다시 선택합니다.

## 증상별 확인 순서

| 증상 | 확인 순서 | 자세한 설명 |
| --- | --- | --- |
| 시작 불가·컴파일 경고 | 작성 → 오류 수정 → 컴파일 → 시작 | [래더](06-programming.md) |
| 필요한 부품이 없음 | 자격증·기능 필터 둘 다 전체 | [부품 목록](03-components.md) |
| 핀이 잘 선택되지 않음 | 확대 → 핀 이름 → 선 끝 위치 | [배선](04-wiring.md) |
| Y ON인데 구동 안 됨 | 전원·0V → 출력 모드 → 밸브/드라이버 → 물리 조건 | [기계](11-mechanics.md) |
| 센서가 안 잡음 | 전원 → 검출 대상 → 위치·방향 → Z → SIG/X | [센서](11-mechanics.md) |
| 부품이 사라짐 | L의 숨김·불투명도·앞뒤 순서 → 캔버스 위치 | [L](10-render-layers.md) |
| 겹쳐도 적재·충돌 안 됨 | 실제 접촉 Z·작업 위치·기계 동작 | [Z](09-z-layers.md) |
| HMI 버튼이 안 먹음 | 24V·0V → PLC 한 개 → RUN → 일시정지 → M 주소 | [HMI](08-hmi.md) |
| HMI 숫자를 수정할 수 없음 | 숫자 표시는 읽기 전용. M 버튼과 래더로 값 변경 | [HMI](08-hmi.md) |
| 저장 후 래더/배선이 빠짐 | JSON/CSV만 저장했는지 확인 → 통합 프로젝트 저장 | [파일](02-projects.md) |
| 자동 순서 중간 정지 | 요청 → 단계 M → 명령 → 구동 → 완료 입력 | [모니터](07-monitoring.md) |
| RTL 분석·빌드 실패 | 저장한 배포판 → Doctor 실패 항목 → 빌드 로그 | [RTL](12-rtl.md) |

문제를 전달할 때는 프로그램 버전, 프로젝트 파일명, RUN/STOP, 마지막 정상 동작,
멈춘 부품·X/Y/M 상태, 오류 문구와 화면을 함께 적으면 확인이 빠릅니다.

## 프로그램 안에서 가이드 읽기

**Ctrl+,**로 도움말을 열고 **사용법 가이드 열기**를 누릅니다. 도움말은 기본 조작과 단축키를 빠르게 찾는 창이고, 가이드는 사진·GIF를 보며 자세히 따라 하는 별도 창입니다.

- 가이드를 열어 둔 채 실배선·래더 편집과 운전을 계속할 수 있습니다. 자동으로 일시정지하지 않습니다.
- 창 가장자리를 드래그해 크기를 바꾸고 프로그램 옆으로 이동합니다.
- 왼쪽 목차에서 장을 선택하거나 검색어를 입력합니다.
- 위쪽 이전·다음 버튼은 읽던 문서로 돌아갑니다. A−·A+는 본문 글자 크기를 바꿉니다.
- 이미지·GIF를 누르면 크게 볼 수 있습니다. 인터넷 없이 문서와 실습 이미지를 읽을 수 있습니다.
- 창을 닫아도 프로그램은 계속 동작합니다. 도움말에서 다시 열 수 있습니다.

가이드가 열리지 않으면 설치 파일의 `resources/help` 폴더와 Microsoft Edge WebView2 Runtime 설치 상태를 확인합니다.
