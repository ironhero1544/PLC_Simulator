# 11. センサー・空圧・モーター・ワーク実習

機械部品は配線・信号条件に加え、**実際の位置・向き・高さ** を合わせる必要があります。
1つの動作を確認してから次の駆動部を接続すると、自動シーケンスの原因を探しやすくなります。

<a id="공압-공급과-복동실린더"></a>

## 空圧供給と複動シリンダー

1. エアサービスユニット（FRL）・ソレノイド・複動シリンダーを配置します。
2. FRLの圧力を設定します。産業技師の例は0.5MPa供給です。
3. FRL OUTをソレノイドPに接続します。
4. ソレノイドA/BをシリンダーA/Bに接続します。
5. ソレノイドコイルの電源・PLC制御線・0Vを接続します。
6. 一度に片方向だけ出力し、前進・後退を確認します。
7. 内蔵センサーは24V・0Vを接続し、FWD/REVをPLC Xへ接続します。

![FRL供給とソレノイドPの空圧配線](../../images/exam03-guide/07-pneumatic.png)

*FRL供給とソレノイドPの空圧配線*


ソレノイドの空圧記号で作動ポートと供給・排気経路を読みます。
シリンダーA/Bを逆にすると、期待する出力とロッド方向が反対になる場合があります。
逆方向のコイルが同時にオンにならないよう、方向別のインターロックを作ります。

<a id="센서와-광화이버"></a>

## センサーと光ファイバー

通常のセンサーは先に電源を接続し、信号ピンをXへ送ります。
誘導型は金属を検出し、静電容量型とは対象が異なるため、部品の説明を確認します。
ワーク経路にセンサーを密集させると、複数が同時に検出して順序が分かりにくくなります。

光ファイバーは **アンプ＋投光ヘッド＋受光ヘッド** を組み合わせます。

1. アンプに24V・0Vを接続します。
2. 光TXを投光ヘッド、RXを受光ヘッドに接続します。
3. アンプSIGをPLC Xに接続します。
4. ヘッド間の検出経路にワークが入るよう、位置と向きを合わせます。
5. センサーとワークのZ高さを確認します。
6. アンプの数値・表示とX入力が一緒に変わることを確認します。

アンプが0000のままなら、まず電源、両方の光接続、ヘッド配置を確認します。
表示は変わるのにPLC Xが変わらない場合は、SIG配線・入力モード・アドレスを確認します。

<a id="dc-모터-드라이버-plc-속도-제어"></a>

## DCモータードライバー：PLCによる速度制御

| ドライバーピン | 接続先／役割 |
| --- | --- |
| 24V / 0V | ドライバー電源 |
| EN | PLC運転許可出力 |
| DIR | PLC方向出力 |
| BRK | PLCブレーキ出力 |
| PWM | PLC PWM出力 |
| M+ / M− | DCモーターの＋／− |

1. モーターをドライバーM+・M−に接続します。
2. 24V・0V電源を接続します。
3. EN・DIR・BRKを選んだPLC出力に接続します。
4. PWMは **Y0～Y3の1つ** に接続します。
5. ラダーでPWMを出力します。条件ON時の `PWM K5 K10 Y0` は、
   ON時間5ms／周期10ms、デューティ50%です。
6. ENをオンにしBRKを解除して、方向と速度を確認します。

EN・DIR・BRKはすべてY0固定ではありません。ただし **PWMはY0～Y3のみ** 対応です。
1つのPWMピンに複数の出力を接続しません。
PWM命令がなく通常のYだけがONなら100%、OFFなら0%として扱われます。
可変抵抗を回す実習ではありません。PWM制御に独立したアナログ出力モジュールは不要です。
同じYにPWMと通常のOUTやサーボ移動命令を同時に割り当てません。

<a id="서보-리프트와-원점"></a>

## サーボリフトと原点

サーボモーターは **U/V/W・PE・ENC** を使います。ステッピングモーターのA+/A−/B+/B−とは区別します。
アンプ電源、SON・パルス・方向・状態信号、モーター駆動・ENCをピン名に従って接続します。

リフトは回転をボールねじの直線移動に変換します。軸設定は [Z・サーボ軸設定](09-z-layers.ja.md) に従います。
まず原点復帰と短いJOGを確認してから、自動位置決めを作ります。
途中位置でJOGした後、以前の自動段階Mや座標基準を残すと次の移動がずれる場合があります。

<a id="흡착스토퍼"></a>

## 吸着とストッパー

吸着シリンダーはロッド移動と真空を一緒に確認します。パッドをワークの実際の位置・高さに合わせます。
真空がONなだけで離れたワークが自動的に吸着するわけではありません。

ストッパーは、ピンがコンベヤー経路にかかる高さでワークを止めます。
実物同様、非作動高さでは平面図にピンが見えません。常に突き出したロッドではありません。
ストッパー・コンベヤー・ワークの高さを合わせ、ON/OFFで通過・停止を確認します。

<a id="공작물-공급보관"></a>

## ワークの供給と保管

ワーク検出センサーの上にワークを積んで供給スタックを作ります。
最初のワークは作業高さ、待機ワークは上の高さにあります。最初が移動し、
関連駆動部が停止すると次のワークが下りてきます。別のマガジンが持ち上げる方式ではありません。

保存ボックスは同じ作業高さから入った複数のワークを整列して保管します。
6スロット倉庫は各段2スロットです。マウスオーバーなどのプレビューで格納状態を確認します。
取り出す際は選択ツールでワークをドラッグします。選べなければLの非表示・不透明度・手前の部品を確認します。

倉庫を左右に移動させるには **サーボ駆動倉庫** など対応する駆動部品を使います。
空圧駆動倉庫は、A/B圧力でシリンダーが動く別モデルです。
静止倉庫に信号線をつなぐだけでは移動しません。

設備全体の接続例は [産業技師問題3の実習ガイド](../exam03/GUIDE.ja.md) を参照してください。
