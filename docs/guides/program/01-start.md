# 1. 실행과 화면 읽기

처음에는 **실배선에서 부품을 배치하고 연결 → 프로그래밍에서 래더 작성 → 컴파일 → 시작** 순서로 진행합니다.
RTL은 새 Verilog 부품을 만들 때 사용하는 확장 기능입니다. 기본 PLC 실습부터 시작해도 됩니다.

## 실행 파일 선택

| 받은 파일 | 실행 방법 |
| --- | --- |
| 설치 프로그램 EXE 또는 MSI | 설치를 마친 뒤 PLC Simulator 실행 |
| 무설치 ZIP | 폴더 전체를 압축 해제한 뒤 안의 `PLCSimulator.exe` 실행 |
| 단일 EXE | 해당 EXE 실행. 필요한 실행 파일은 로컬 캐시에 자동으로 풀립니다 |

ZIP에서 EXE만 다른 폴더로 옮기면 DLL·글꼴·리소스를 찾지 못할 수 있습니다.
실습 프로젝트는 문서 폴더 등 직접 저장할 수 있는 위치에 보관합니다.
배포 파일의 실제 이름은 버전에 따라 달라질 수 있습니다.

## 화면의 다섯 영역

![실배선 화면의 메뉴·도구·부품 목록. 배치된 장비는 산업기사 예시입니다](../../images/program-guide/02-wiring-overview.png)

*실배선 화면의 메뉴·도구·부품 목록. 배치된 장비는 산업기사 예시입니다*


| 위치 | 역할 | 처음 할 일 |
| --- | --- | --- |
| 맨 위 메뉴 | 프로젝트 저장·불러오기, RTL, 설정 | 저장할 때는 **프로젝트** 메뉴 사용 |
| 모드 버튼 | 실배선 / 프로그래밍 전환 | 부품 배치는 **실배선 모드** |
| 모드 아래 도구 | 선택·배선 또는 작성·모니터·컴파일 | 작업에 맞는 도구 선택 |
| 가운데 캔버스 | 부품·배선 또는 래더 편집 | 충분히 확대해 핀이나 셀 선택 |
| 오른쪽 | 부품 목록 또는 프로그래밍 정보 | 부품 필터, Z·L, 선택 셀 확인 |

오른쪽 위 **STOP / RUN**은 운전 상태입니다. 프로그래밍의 **작성 / 모니터**는 편집·관찰 상태입니다.
모니터 버튼과 시작 버튼은 서로 다른 역할을 합니다.

## 첫 작업 순서

1. **실배선 모드**를 누릅니다.
2. 오른쪽 부품 목록에서 부품을 끌어 캔버스에 놓습니다.
3. **배선**을 선택하고 핀끼리 연결합니다.
4. **프로그래밍 모드 → 작성(F3)**으로 이동합니다.
5. 접점과 코일을 입력하고 **컴파일**을 누릅니다.
6. 오류가 없으면 오른쪽 위 **시작**을 누릅니다.
7. **모니터(F2)**에서 조건과 출력을 확인합니다.
8. **프로젝트 → 프로젝트 저장…**으로 저장합니다.

```mermaid
flowchart LR
  A[부품 배치] --> B[배선]
  B --> C[래더 작성]
  C --> D[컴파일]
  D --> E[시작과 모니터]
  E --> F[프로젝트 저장]
```
