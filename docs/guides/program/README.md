# PLC Simulator 사용법 가이드

**부품을 놓고 배선하는 방법부터 래더 작성·운전·HMI·레이어·RTL까지 직접 조작하는 순서로 설명합니다.**
프로그램에서 **Ctrl+, → 사용법 가이드 열기**로 읽을 수 있습니다. 가이드 창을 옆에 두고 프로그램을 계속 조작할 수 있으며 창 크기와 글자 크기를 조절할 수 있습니다. GitHub에서도 같은 Markdown 문서를 읽을 수 있습니다.

처음 사용한다면 **1~5장**을 순서대로 읽고 버튼·램프 실습을 진행하세요.
이미 기본 조작을 알고 있다면 필요한 장으로 바로 이동하세요.
