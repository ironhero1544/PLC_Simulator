# 3. 부품 찾기·배치·이름 표시

부품은 오른쪽 목록에서 찾습니다. 목록의 필터는 **자격증**과 **기능**으로 나뉩니다.
배치한 뒤에는 선택도구로 위치를 조절합니다.

## 필요한 부품만 찾기

1. 목록 위쪽 자격증 필터를 엽니다.
2. 일반 실습은 **전체**, 시험 연습은 **자동화설비산업기사** 등 해당 항목을 선택합니다.
3. 그 아래 기능 필터를 엽니다.
4. 전원·제어·공압·센서 등 필요한 항목으로 좁힙니다.
5. 원하는 부품이 없으면 두 필터를 **전체 / 전체 기능**으로 되돌립니다.

![자격증 필터를 여는 실제 화면](../../images/automation-exam-03/04-certificate-filter-menu.png)

*자격증 필터를 여는 실제 화면*

## 부품 배치와 이동

1. 부품 목록의 카드를 캔버스로 드래그합니다.
2. **선택도구**를 누릅니다. 배선 도구가 선택된 상태에서는 핀을 클릭하면 연결 작업을 시작할 수 있습니다.
3. 부품 몸체를 클릭해 선택하고 끌어서 위치를 바꿉니다.
4. 빈 공간에서 사각형을 드래그하면 여러 부품을 함께 선택합니다.
5. Ctrl을 누르고 부품을 클릭하면 선택을 추가하거나 해제합니다.
6. 선택된 부품을 이동합니다. 배선이 있는 경우 이동 후 연결 경로도 확인합니다.

처음부터 PLC·전원·구동부를 한곳에 밀집시키면 핀 선택과 운전 관찰이 어려워집니다.
전원·PLC는 위쪽, 구동부는 아래쪽에 두고 호스와 배선이 지나갈 여백을 확보합니다.

## 확대·축소와 화면 이동

| 조작 | 결과 |
| --- | --- |
| 마우스 휠 / 트랙패드 핀치 | 확대·축소 |
| 가운데 버튼을 누르고 드래그 | 화면 이동 |
| Alt + 오른쪽 버튼 드래그 | 화면 이동 |
| Shift + 휠 | 가로 이동 |
| 트랙패드 두 손가락 스크롤 | 화면 이동 |

핀을 고를 때는 핀 이름을 읽을 수 있게 확대합니다. 트랙패드의 두 손가락 스크롤은
휠 확대와 다른 이동 동작으로 처리될 수 있으므로 화면 하단의 Zoom 값을 확인합니다.

## 회전·반전·삭제

1. 선택도구로 부품을 선택합니다.
2. `R`은 90도 회전, `Shift+R`은 반대 방향 회전입니다.
3. 몸체 더블클릭 메뉴에서 회전·수평 뒤집기·수직 뒤집기를 선택할 수도 있습니다.
4. 삭제는 선택한 뒤 `Delete`를 사용합니다.
5. 잘못 편집했다면 `Ctrl+Z`, 되돌린 편집을 다시 적용하려면 `Ctrl+Y` 또는 `Ctrl+Shift+Z`를 누릅니다.

![PLC 부품을 선택하고 R·Shift+R로 회전하기](../../images/program-guide/component-rotate.gif)

*PLC 부품을 선택하고 R·Shift+R로 회전하기*

회전 후에는 로드 방향과 핀 위치가 함께 바뀌므로 배선과 기계 동작 방향을 다시 확인합니다.

## 캔버스에 글씨 넣기

부품 설명용 글씨는 **부품 이름 표시**를 사용합니다.

1. 선택도구에서 부품 몸체를 더블클릭합니다.
2. **부품 이름 편집**을 엽니다.
3. `공급 실린더`, `가공 감지 X2`처럼 이름을 입력합니다.
4. Enter로 적용합니다.
5. 같은 메뉴에서 **이름 표시하기**를 켭니다.
6. 빈 이름으로 지우거나 표시 체크를 끄면 이름표를 숨길 수 있습니다.

![부품 이름 편집의 이름 표시하기. 이전 산업기사 장면의 메뉴 예시입니다](../../images/automation-exam-03/part-name-display-menu.jpg)

*부품 이름 편집의 이름 표시하기. 이전 산업기사 장면의 메뉴 예시입니다*

HMI 화면 안의 글씨는 별도로 **화면 편집 → + 고정 글자**에서 만듭니다.
부품 이름과 HMI 위젯의 글자는 서로 다른 설정입니다.
