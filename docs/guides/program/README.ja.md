# PLC Simulatorユーザーガイド

**部品配置・配線からラダー作成・運転・HMI・レイヤー・RTLまで、実際の操作順で説明します。**
プログラムの **Ctrl+, → ユーザーガイドを開く** で読めます。横に置いたまま操作を続けられ、ウィンドウと文字サイズを変更できます。同じMarkdown文書をGitHubでも読めます。

初めて使う場合は **1～5章** を順に読み、ボタン・ランプ実習を進めてください。
基本操作を知っている場合は、必要な章へ直接進んでください。
