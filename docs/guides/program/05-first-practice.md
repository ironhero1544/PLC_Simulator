# 5. 첫 실습: 버튼으로 램프 켜기

이번 실습은 버튼을 누르는 동안 같은 유닛의 램프가 켜지도록 만듭니다.
완성 파일을 불러오는 대신 **부품 3개, 배선 4가닥, 래더 한 회로**를 직접 만듭니다.

## 준비

현재 작업을 `.plcproj`로 보관하고 별도 실습에서 진행합니다. 빈 작업 화면이 필요하면
작업을 저장한 뒤 앱을 새로 실행합니다. 기존 설비의 출력 주소와 겹치지 않게 합니다.

| 부품 | 수량 | 역할 |
| --- | --- | --- |
| PLC | 1 | X0 입력을 읽고 Y0 출력 제어 |
| DC 전원 공급기 | 1 | 버튼·램프 회로의 24V 공급 |
| 램프/버튼 유닛 | 1 | 첫 번째 버튼과 첫 번째 램프 사용 |

## 1단계: 배치와 모드

1. 실배선에서 위 세 부품을 끌어 놓습니다.
2. 전원은 왼쪽, PLC는 가운데, 버튼 유닛은 오른쪽에 두고 배선할 여백을 남깁니다.
3. PLC 몸체를 더블클릭해 **입력 Sink / 출력 Source**로 맞춥니다.
4. 버튼 유닛의 **첫 번째 행** 핀 이름을 확인합니다. 각 행은 COM·NO·NC와 램프 24V·0V를 사용합니다.

## 2단계: 네 가닥 배선

| 순서 | 시작 핀 | 도착 핀 |
| --- | --- | --- |
| 1 | DC 전원 24V | 첫 번째 버튼 COM |
| 2 | 첫 번째 버튼 NO | PLC X0 |
| 3 | PLC Y0 | 첫 번째 램프 24V |
| 4 | DC 전원 0V | 첫 번째 램프 0V |

**NC는 이번 실습에서 사용하지 않습니다.** 버튼의 접점 전원과 램프 전원 핀을 구분합니다.
PLC 그림에는 별도 전원 배선용 핀이 없으므로 임의의 전원 핀을 찾거나 X/Y를 전원 핀처럼 연결하지 않습니다.

![첫 번째 배선 24V → 버튼 COM을 경유점으로 연결하는 실제 조작 단계](../../images/program-guide/wiring-route.gif)

*첫 번째 배선 24V → 버튼 COM을 경유점으로 연결하는 실제 조작 단계*

## 3단계: 래더 입력

1. **프로그래밍 모드 → 작성(F3)**을 누릅니다.
2. END 위의 회로 왼쪽 셀을 클릭합니다. END만 있으면 `Insert`로 회로를 추가합니다.
3. `F5`를 누릅니다.
4. 주소에 `X0`을 입력하고 Enter로 확정합니다.
5. 같은 회로의 다음 빈 셀을 선택하고 `F7`을 누릅니다.
6. `Y0`을 입력하고 Enter로 확정합니다.
7. X0 접점에서 Y0 코일까지 선이 이어지고 END가 마지막에 있는지 확인합니다.

```text
X0가 ON이면 → Y0 ON
X0가 OFF이면 → Y0 OFF
```

이 텍스트는 동작 설명입니다. 래더 화면에는 X0 접점과 Y0 코일을 각각 입력합니다.
접점·명령 입력창의 실제 모습은 [래더 작성 장](06-programming.md)에 있습니다.

## 4단계: 컴파일과 운전

1. **컴파일**을 누릅니다. 실패하면 오류 내용을 읽고 해당 입력을 수정합니다.
2. 성공한 뒤 오른쪽 위 **시작**을 누릅니다.
3. 실배선으로 돌아가 **선택도구**를 선택합니다.
4. 첫 번째 버튼을 누른 채 램프를 확인합니다.
5. 버튼을 놓으면 램프가 꺼지는지 확인합니다.
6. 프로그래밍의 **모니터(F2)**에서도 X0 접점과 Y0 상태가 함께 변하는지 확인합니다.
7. **프로젝트 → 프로젝트 저장…**에서 `버튼램프_01.plcproj`로 보관합니다.

## 안 켜질 때의 순서

| 관찰 | 먼저 확인할 항목 |
| --- | --- |
| X0도 안 켜짐 | 24V→COM, NO→X0, 실제 누른 버튼 행, 입력 모드 |
| X0는 켜지는데 Y0가 OFF | 래더 주소, 컴파일 성공, RUN 상태 |
| Y0는 켜지는데 램프가 안 켜짐 | Y0→램프 24V, 램프 0V, 출력 Source 여부 |
| 버튼을 놓아도 계속 켜짐 | NO 대신 NC 사용 여부, 다른 회로에서 Y0 제어 여부 |
