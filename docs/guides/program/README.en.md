# PLC Simulator user guide

**Learn hands-on steps from placing and wiring components to ladder editing, running, HMI, layers, and RTL.**
Open it in the app with **Ctrl+, → Open user guide**. Keep the guide beside the app while working, and resize the window or text. The same Markdown documents can be read on GitHub.

New users should read **chapters 1–5** in order and complete the button/lamp exercise.
If you know the basics, go directly to the chapter you need.
