# 4. 電気・空圧・光の配線

ツールは **配線** の1つです。**開始ピンに応じて電線・空圧ホース・光接続の種類が自動的に決まります。**
線の色よりも、ピン名と接続種類を先に確認します。

<a id="선-한-가닥-연결"></a>

## 1本の配線を接続する

1. **配線 → 配線** を選びます。
2. 開始ピンをクリックします。ピンが密集している場合は先に拡大します。
3. 線を曲げる位置の空白部分をクリックし、経由点を作ります。
4. 次の経由点も同じように作ります。
5. 終点のピンをクリックして接続を完了します。
6. 開始ピンを間違えた場合は、接続中に右クリックで取り消してやり直します。
7. 両端のピン名と経路を確認します。

![24V → ボタンCOM：開始ピン・2つの経由点・終点ピンの操作](../../images/program-guide/wiring-route.gif)

*24V → ボタンCOM：開始ピン・2つの経由点・終点ピンの操作*

経由点は線の通り道です。画面で別の線と交差しても接続点にはなりません。
実際の接続は部品のピン同士の接続関係で確認します。

<a id="전원과-제어선을-분리해서-작업"></a>

## 電源と制御を分けて配線する

| 種類 | 接続例 | 確認事項 |
| --- | --- | --- |
| 電源 | DC 24V → センサー24V、DC 0V → センサー0V | 両方を接続 |
| 入力 | センサーSIG/FWD/REV → PLC X | ラダーの入力アドレスに合わせる |
| 出力 | PLC Y → バルブコイル／ドライバー制御ピン | 駆動電源と戻り線も必要 |
| 空圧 | FRL OUT → バルブP → シリンダーA/B | 供給・作動・排気ポートを区別 |
| 光 | アンプTX/RX → 投光／受光ヘッド | 電気SIGと光ポートを区別 |

![24Vと0Vをそれぞれ接続した電源配線例](../../images/exam03-guide/05-power-pair.png)

*24Vと0Vをそれぞれ接続した電源配線例*

*写真はサーボアンプです。他の部品も同様に24Vと0Vをそれぞれ確認します。*

<a id="plc-입력출력-모드-확인"></a>

## PLCの入出力モードを確認する

1. 選択ツールでPLCの本体をダブルクリックします。
2. 入力の **Sink／Source** と出力モードを確認します。
3. 選んだモードに合わせて供給電圧と戻り経路を接続します。
4. 出力モードを変更した場合は、バルブ・ランプ・ドライバーの配線も見直します。

以下の最初の実習は **入力Sink／出力Source** です。異なるモードで同じ配線を使うと、
入力または出力が動作しない場合があります。

<a id="배선-정돈과-태그"></a>

## 配線の整理とタグ

電源線は上、制御線はPLC周辺、空圧ホースは駆動部の下など、経路を分けると読みやすくなります。
本体や名前ラベルを横切る長い斜線ではなく、余白を使った直角の経路にします。

長い接続を短く表示するには、**タグ** を選んで既存の配線をクリックします。
タグ名と色を設定します。タグは既存接続の表示方法であり、別の電源や信号は作りません。
タグを外すには、そのタグ／配線を **Alt＋右クリック** します。
実際の接続経路を確認する際は、タグを解除して確認します。

![配線埋め込みで長い接続を簡潔に表示](../../images/program-guide/wire-tags.gif)

*配線埋め込みで長い接続を簡潔に表示*

<a id="수정-후-확인"></a>

## 修正後の確認

選択・削除・元に戻す操作で誤った接続を修正します。ピンが隣接していると、
隣のピンをクリックしてしまう場合があるので、拡大して線の終点を確認します。
