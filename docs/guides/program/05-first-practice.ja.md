# 5. 最初の実習：ボタンでランプを点灯

ボタンを押している間、同じユニットのランプが点灯するようにします。
完成ファイルを読み込まず、**部品3個・配線4本・ラダー1回路** を自分で作ります。

<a id="준비"></a>

## 準備

現在の作業を `.plcproj` に保存し、別の実習として進めます。空の画面が必要なら、
作業を保存してアプリを起動し直します。既存設備の出力アドレスと重ならないようにします。

| 部品 | 数量 | 役割 |
| --- | --- | --- |
| PLC | 1 | X0を読み取りY0を制御 |
| DC電源 | 1 | ボタン・ランプ回路に24Vを供給 |
| ランプ／ボタンユニット | 1 | 最初のボタンとランプを使用 |

<a id="1단계-배치와-모드"></a>

## 手順1：配置とモード

1. 上記3つの部品を実配線にドラッグします。
2. 電源を左、PLCを中央、ボタンユニットを右に置き、配線の余白を残します。
3. PLC本体をダブルクリックし、**入力Sink／出力Source** にします。
4. ボタンユニットの **1段目** のピン名を確認します。各段はCOM・NO・NCとランプの24V・0Vを使います。

<a id="2단계-네-가닥-배선"></a>

## 手順2：4本の配線

| 順序 | 開始ピン | 終点ピン |
| --- | --- | --- |
| 1 | DC電源24V | 最初のボタンCOM |
| 2 | 最初のボタンNO | PLC X0 |
| 3 | PLC Y0 | 最初のランプ24V |
| 4 | DC電源0V | 最初のランプ0V |

**この実習ではNCを使いません。** ボタン接点の電源とランプの電源ピンを区別します。
PLCの図には独立した電源ピンがないため、存在しない電源ピンを探したりX/Yを電源ピンとして接続したりしません。

![最初の配線：24V → ボタンCOMを経由点で接続](../../images/program-guide/wiring-route.gif)

<a id="3단계-래더-입력"></a>

## 手順3：ラダー入力

1. **プログラミング → 編集（F3）** を押します。
2. ENDの上にある回路の左セルをクリックします。ENDだけの場合は `Insert` で回路を追加します。
3. `F5` を押します。
4. アドレスに `X0` を入力し、Enterで確定します。
5. 同じ回路の次の空セルを選び、`F7` を押します。
6. `Y0` を入力し、Enterで確定します。
7. X0接点からY0コイルまで線がつながり、最後にENDがあることを確認します。

```text
X0가 ON이면 → Y0 ON
X0가 OFF이면 → Y0 OFF
```

このテキストは動作説明です。ラダー画面にはX0接点とY0コイルをそれぞれ入力します。
接点・命令の入力画面は [ラダー作成の章](06-programming.ja.md) にあります。

<a id="4단계-컴파일과-운전"></a>

## 手順4：コンパイルと運転

1. **コンパイル** を押します。失敗したらエラーを読み、該当箇所を修正します。
2. 成功したら右上の **実行** を押します。
3. 実配線へ戻り、**選択ツール** を選びます。
4. 最初のボタンを押したままランプを確認します。
5. ボタンを離してランプが消えることを確認します。
6. プログラミングの **モニター（F2）** でもX0接点とY0が一緒に変わることを確認します。
7. **プロジェクト → プロジェクトを保存…** で `button_lamp_01.plcproj` として保存します。

<a id="안-켜질-때의-순서"></a>

## 点灯しない場合の確認順

| 状態 | 最初に確認する項目 |
| --- | --- |
| X0もオンにならない | 24V→COM、NO→X0、押したボタンの段、入力モード |
| X0はオンだがY0はOFF | ラダーのアドレス、コンパイル成功、RUN状態 |
| Y0はオンだがランプが消灯 | Y0→ランプ24V、ランプ0V、出力Source |
| ボタンを離しても点灯 | NOの代わりにNCを使っていないか、別の回路がY0を制御していないか |
