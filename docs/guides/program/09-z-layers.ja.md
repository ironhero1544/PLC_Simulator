# 9. Zレイヤー：実際の高さと移動範囲

**Zは物理的な高さ** です。画面で重なっても接触高さが合わなければ、衝突・検出・格納は成立しません。
見える前後関係だけを変更するには、次の章の **L表示レイヤー** を使います。

<a id="설정창-열기"></a>

## 設定画面を開く

1. 実配線の部品一覧の横にある **Z** を押します。
2. 一覧で設定する部品を選びます。
3. **シミュレーションを一時停止して編集** をチェックします。チェック前は入力欄が無効の場合があります。
4. 固定部品は **設置高さ**、動く部品は **最小・最大・初期高さ** を設定します。
5. **高さを適用** を押します。
6. 編集後に一時停止を解除し、実際の動作を確認します。
7. プロジェクトとして保存します。

![Zレイヤー画面と設置高さ](../../images/program-guide/03-z-layer.png)

*Zレイヤー画面と設置高さ*


*写真はPLCの固定高さの例です。動く部品を選ぶと高さ範囲と軸の設定が表示されます。*

部品のダブルクリックメニューからZ設定を開くと、その部品を直接選んで編集できます。
一覧の `Z 1.00` などの値は、現在の接触高さを確認する際に使います。

<a id="범위-설정-예"></a>

## 範囲の設定例

| 部品 | 最小 | 最大 | 意味 |
| --- | --- | --- | --- |
| コンベヤー上のワーク | 1 | 1 | Z1で移動・検出 |
| 加工シリンダー | 1 | 2 | 下が作業高さ、上が待機高さ |
| サーボリフト | 1 | 3 | 移動量に応じてZ1～3で変化 |
| 6スロット倉庫 | 1 | 3 | 各高さに2スロット |

この数値は **実習の設定例** です。すべての部品が絶対Z1から始まる必要はありません。
最小≤初期≤最大に設定し、相互作用するワーク・センサー・駆動部の高さを合わせます。
範囲内では中間の高さも表すため、整数レイヤー間だけの移動ではありません。

<a id="창고-슬롯과-높이"></a>

## 倉庫スロットと高さ

Z1～3の倉庫は **1・2番がZ1、3・4番がZ2、5・6番がZ3** に対応します。
リフトを該当する高さに上げ、左右位置を合わせてからワークを置きます。
画面で倉庫と重なっただけで、すべての段へ同時に格納されるわけではありません。

<a id="서보-축-설정"></a>

## サーボ軸の設定

サーボリフトなどの対象部品を選ぶと、軸設定を編集できます。

| 項目 | 意味 | 確認する場面 |
| --- | --- | --- |
| 1回転あたりのパルス | モーター1回転のパルス数 | パルス数と移動量が合わない場合 |
| リード mm/回転 | ボールねじ1回転の直線移動量 | 速度・距離の換算 |
| ストローク mm | 軸の移動範囲 | 目標位置が範囲外の場合 |
| 最大速度 rev/s | 回転速度の上限 | 速すぎる、所要時間が違う場合 |
| 加速度 rev/s² | 回転加速度 | 起動・停止時の変化 |

高さと軸設定はそれぞれの適用ボタンを確認します。HMIのmm/min値と
軸設定のrev/sは同じ数値ではありません。原点や移動命令の基準も合わせます。
