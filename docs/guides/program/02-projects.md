# 2. 프로젝트 저장·불러오기

실습 전체를 계속 작업하려면 **`.plcproj` 통합 프로젝트**로 저장합니다.
실배선의 JSON 저장과 프로그래밍의 CSV 저장은 각각 한 영역을 따로 보관하는 기능입니다.

## 파일과 여는 위치

| 파일 | 담는 내용 | 여는 곳 |
| --- | --- | --- |
| `.plcproj` | 부품·배선·래더·HMI 설정·레이어·프로젝트 RTL 데이터 | **프로젝트 → 프로젝트 불러오기…** |
| `.json` | 실배선 레이아웃과 그 안의 설정 | **실배선 모드 → 불러오기** |
| `.csv` | 래더 프로그램 | **프로그래밍 모드 → 불러오기** |
| `.plccomp` | 재사용할 RTL 부품 패키지 | **RTL 라이브러리 → 부품 가져오기** |

![프로젝트 메뉴. 통합 저장·불러오기는 이 메뉴에 있습니다](../../images/program-guide/01-project-menu.png)

*실제 프로젝트 메뉴. 통합 저장·불러오기는 이 메뉴에 있습니다*


## 전체 실습 저장

1. 위쪽 **프로젝트 → 프로젝트 저장…**을 누릅니다. `Ctrl+S`도 같은 저장 창을 엽니다.
2. 저장할 폴더를 선택합니다.
3. `버튼램프_01.plcproj`처럼 알아볼 수 있는 이름을 입력합니다.
4. 저장을 완료합니다. 기존 파일을 덮어쓸 때는 선택한 파일명이 맞는지 확인합니다.
5. 중요한 변경 전에는 `버튼램프_02.plcproj`처럼 다른 이름으로 한 번 더 보관합니다.

## 다시 열어 이어서 작업

1. 현재 작업을 먼저 저장합니다.
2. **프로젝트 → 프로젝트 불러오기…**를 누릅니다.
3. `.plcproj` 파일을 선택합니다.
4. 실배선에서 부품·배선·HMI 설정을 확인합니다.
5. 프로그래밍에서 래더가 함께 들어왔는지 확인합니다.
6. 컴파일 상태를 확인하고, 변경했거나 컴파일이 필요하면 다시 컴파일합니다.
7. 운전을 시작하기 전에 공작물 위치와 원점 상태를 확인합니다.

프로젝트를 불러오는 것은 기존 작업에 부품을 몇 개 추가하는 작업으로 생각하지 말고,
그 파일의 실습을 여는 작업으로 생각하면 됩니다.

## 배치 또는 래더만 따로 저장할 때

실배선 도구의 **저장**은 JSON 레이아웃을 저장합니다. 래더까지 저장한 것으로 생각하면 안 됩니다.
반대로 프로그래밍 도구의 **저장**은 CSV입니다. 배선이 함께 들어가지는 않습니다.

산업기사 가이드의 **배치 전용 JSON**도 부품 위치부터 연습하기 위한 파일입니다.
그 파일을 열었다고 전원 배선·제어 배선·HMI·래더가 완성되는 것은 아닙니다.
