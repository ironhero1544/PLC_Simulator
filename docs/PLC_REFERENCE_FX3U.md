# FX3U/FX3UC PLC 기준 규칙

이 문서는 시뮬레이터의 PLC 동작을 수정할 때 지켜야 하는 기준 문서다. UI의 편의 모델이나 일반적인 PLC 상식보다 이 문서와 실제 대상 기종의 하드웨어 사양을 우선한다.

## 기준 자료

- `FX3_시리즈_프로그래밍_매뉴얼kor.pdf` - FX3U/FX3UC 기본·응용 명령, 디바이스, 입출력 Refresh, 특수 디바이스
- `FX3U_하드웨어_매뉴얼(KOR).pdf` - FX3U 하드웨어 입출력 회로 및 배선
- `FX3U ( 하드웨어 )사용자 매뉴얼.pdf` - FX3UC 하드웨어 사용자 매뉴얼

문서 원본은 사용자 로컬 `Downloads`에 있으며, 이 저장소 문서는 원본을 대체하지 않는다. 매뉴얼은 2004~2006년 판본이므로 실제 적용 기종과 출력 형식은 반드시 모델별 사양을 확인한다.

## 1. PLC 1스캔의 기준 동작

FX3U/FX3UC의 일괄 입출력 Refresh 방식은 다음 순서를 기본으로 한다.

1. 스캔 시작 전에 실제 입력 단자 상태를 입력 Image Memory에 일괄 저장한다.
2. 0 Step부터 `END`까지 시퀀스 프로그램을 실행한다.
3. 프로그램이 계산한 출력 Image Memory를 `END` 실행 시 실제 출력에 일괄 반영한다.
4. 프로그램 중간에 최신 입력을 읽거나 계산 결과를 즉시 출력해야 할 때만 `REF(FNC 50)`를 사용한다.

따라서 일반 코일 명령을 실행한 즉시 외부 액추에이터를 변경하면 안 된다. 기본 경로에서는 `END` 시점의 출력 Image Memory가 외부 출력의 원자적 갱신 지점이다.

입력에는 채터링·노이즈 억제를 위한 약 10 ms C-R 필터가 있고, 일부 X 디바이스에는 별도 Digital Filter가 적용된다. 고속 카운터, 입력 인터럽트, 펄스 캐치와 일반 입력 스캔을 같은 방식으로 취급하면 안 된다.

`M8039`를 ON하고 `D8039`에 스캔 시간을 지정하면 Constant Scan 모드가 된다. 프로그램 실행이 지정 시간보다 빨리 끝나도 다음 스캔으로 즉시 넘어가지 않고 지정 시간까지 대기한다.

## 2. 디바이스 의미와 주소 규칙

| 디바이스 | 의미 | 시뮬레이터 규칙 |
| --- | --- | --- |
| `X` | 외부 입력 릴레이/Image Memory | 실제 입력을 읽는 PLC 입력 이미지. 프로그램이 임의로 외부 입력을 직접 쓰지 않는다. |
| `Y` | 외부 출력 릴레이/Image Memory | 프로그램 결과를 보관하고 `END`에서 외부 출력으로 반영한다. |
| `M` | 보조 릴레이 | PLC 내부 논리용이며 외부 단자를 직접 구동하지 않는다. |
| `S` | State | STL/SFC 상태 제어용 내부 디바이스다. |
| `T` | Timer | 접점 상태와 현재값/설정값을 분리한다. |
| `C` | Counter | 접점 상태와 현재값/설정값을 분리한다. |
| `D` | Data Register | 16 bit 데이터 레지스터이며 필요 시 2개를 조합해 32 bit로 취급한다. |

`X`와 `Y` 번호는 십진수 연속 번호가 아니라 8진수 주소 규칙을 사용한다. 예를 들어 `X000`~`X007` 다음은 `X010`이다. `Y`도 같은 규칙을 따른다. 모델별 기본 유니트와 증설 유니트의 점수·할당은 실제 기종 설정에서 정한다.

## 3. FX3U 기본 특수 디바이스

- `M8000`: RUN 중 ON인 특수 보조 릴레이
- `M8002`: RUN 시작 시 초기 펄스
- `M8033`: STOP 후에도 RUN 중 출력 상태를 보존하는 Memory Hold Stop
- `M8034`: 전체 출력 금지. 실제 출력은 모두 OFF가 되지만 출력 Image Memory의 논리 상태와 실제 출력 상태를 동일시하지 않는다.
- `M8039` / `D8039`: Constant Scan 모드와 지정 스캔 시간
- `M8031` / `M8032`: 비-Keep / Keep 영역 Clear

특수 디바이스는 일반 내부 비트처럼 임의의 물리 상태로 합성하지 않고, PLC 실행 상태와 디바이스 표에 따라 생성한다.

## 4. FX3U DC24V 입력 회로

FX3U 하드웨어 매뉴얼의 DC24V 입력은 싱크·소스 공통형이다.

- 입력 신호 기준: `DC24V ±10%`
- 싱크 입력: `X` 단자와 `0V` 사이에 무전압 접점 또는 NPN 오픈 컬렉터 출력을 연결한다.
- 소스 입력: `X` 단자와 `24V` 사이에 무전압 접점 또는 PNP 오픈 컬렉터 출력을 연결한다.
- 입력 ON은 입력 회로의 포토커플러/LED가 정해진 전류 조건을 만족할 때 성립한다.
- 일반 입력은 하드웨어 필터와 Digital Filter의 영향을 받으므로, UI에서 접점을 누른 즉시 PLC Image Memory가 바뀐다고 가정하지 않는다.
- `REFF(FNC 51)`는 입력 Filter 설정을 변경하는 명령이며 일반 입력 Refresh와 동일하지 않다.

`[24+]` 및 `[24V]` 서비스 전원 단자는 기본/증설 유니트에 외부 전원을 다시 공급하는 용도로 사용하지 않는다. 기본/증설 유니트 접지는 매뉴얼의 접지 규칙을 따르고 강전계와 공통 접지하지 않는다.

## 5. FX3U 트랜지스터 출력 회로

트랜지스터 출력은 싱크 출력과 소스 출력이 별도 제품으로 존재한다.

- 싱크 출력(`-COM`): 부하 전류가 출력 `Y` 단자로 흘러 들어가는 구조다. `COM`은 부하 전원의 마이너스 측에 연결한다.
- 소스 출력(`+COM` 또는 `+V`): 부하 전류가 출력 `Y` 단자에서 흘러 나가는 구조다. `+V`는 부하 전원의 플러스 측에 연결한다.
- 서로 다른 `COM` 그룹은 내부적으로 연결되어 있다고 가정하지 않는다.
- 서로 다른 `+V` 그룹도 내부적으로 연결되어 있다고 가정하지 않는다.
- 트랜지스터 부하 회로의 외부 전원은 매뉴얼의 허용 전압 범위와 해당 모델의 전류 사양을 사용한다.
- 출력 회로는 포토커플러로 내부 논리와 절연되며, 출력 LED/동작 표시와 실제 부하 전류를 동일한 상태로 간주하지 않는다.

릴레이 출력, 트라이액/SSR 출력, 트랜지스터 출력은 전류 방향·응답 시간·허용 부하가 다르므로 하나의 `Output` 모델로 뭉개지 않는다.

## 6. 시뮬레이터에 적용할 불변조건

1. 입력은 `실제 회로 상태 -> 하드웨어 입력 회로 -> 입력 Image Memory -> PLC 프로그램` 순서로 흐른다.
2. 출력은 `PLC 프로그램 -> 출력 Image Memory -> 출력 타입별 회로 -> 부하` 순서로 흐른다.
3. `X`, `Y`, `M`, `T`, `C`, `D`를 같은 bool 저장소로 취급하지 않는다.
4. 싱크/소스 방향과 `0V`/`24V` 기준은 컴포넌트 설정 및 포트 메타데이터로 명시한다.
5. 화면에 보이는지, 선택됐는지, viewport 안에 있는지는 PLC 물리 결과를 바꾸지 않는다.
6. `END` 이전의 중간 결과와 `REF`에 의한 즉시 Refresh를 구분한다.
7. 입력 필터·스캔 시간·타이머 시간은 실제 `deltaTime`과 분리하지 않는다.
8. 실제 기종이 확정되지 않은 포트 전압·전류·공통 방향은 추측으로 채우지 않는다.

## 아직 확정하지 않은 항목

- 대상이 FX3U인지 FX3UC인지, 정확한 기본 유니트 형명
- 입력이 싱크형인지 소스형인지
- 출력이 릴레이인지 트랜지스터 싱크/소스인지
- 프로젝트 각 컴포넌트의 실제 포트 번호와 전기적 연결 규칙
- 공압 컴포넌트의 압력 기준, 밸브 포트 표기, 실린더 센서 논리

위 항목은 코드에서 일반화하기 전에 사용자의 기준 회로 또는 대상 모델 사양으로 확정한다.
