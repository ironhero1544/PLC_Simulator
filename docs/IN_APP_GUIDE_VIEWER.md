# 프로그램 내 도움말과 가이드

Ctrl+, 또는 기존 Ctrl+/로 도움말을 열고 **사용법 가이드 열기**를
선택합니다. 도움말은 접을 수 있는 기본 조작·단축키 목록이고,
사용법 가이드는 PLC Simulator 창 위에 표시되는 별도 Windows 창에서 Markdown 문서를 읽는 뷰어입니다.
두 창 모두 크기를 조절할 수 있으며 운전·배선·래더 편집을 막거나
시뮬레이션을 자동으로 일시정지하지 않습니다.

가이드 창에는 목차와 전체 문서 검색, 이전·다음 이동, 글자 크기 조절,
이미지·GIF 확대, 코드 복사가 있습니다. CommonMark/GFM의 제목·목록·표·
체크 목록·링크·취소선·코드·인용·HTML을 렌더링하며 수식(KaTeX)과
Mermaid 논리도도 표시합니다. HTML은 DOMPurify로 정리합니다.

문서는 `docs/guides/program`의 Markdown을 원본으로 사용합니다.
`scripts/package_guides.py`가 문서의 내부 링크와 로컬 미디어를 따라
필요한 자료를 `resources/help`에 묶습니다. 문서 로딩과 GIF 재생은
인터넷 연결 없이 동작합니다. 외부 웹 링크를 직접 누르는 경우에는
시스템 브라우저를 엽니다. 외부 배지 이미지 등은 대체 텍스트로
표시하므로 읽을 때 네트워크 요청을 만들지 않습니다.

CMake 빌드 시 Python 3으로 리소스를 생성하고 설치 대상에도 포함합니다.
가이드 창은 WebView2 Runtime을 사용합니다. 실행 환경에 Runtime이나
가이드 리소스가 없으면 도움말 안에 오류를 표시합니다.

검증: 앱·런타임 테스트 빌드, 오프라인 47개 문서의 173개 이미지
표시와 59개 표 렌더링, 링크·뒤로/앞으로 이동·검색·작은 창·글자 확대·
이미지 확대·수식·Mermaid·스크립트 제거 검증을 진행했습니다.
