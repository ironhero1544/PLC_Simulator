# 실배선 신규 부품 물리 동작·핀아웃 명세

작성일: 2026-10-04  
상태: 구현 전 명세. 사용자 확정 요구사항과 시뮬레이터 구현 제안을 구분함.

## 1. 문서 관계와 적용 범위

[전체 구현 계획](WIRING_Z_LAYER_COMPONENT_PLAN.md)의 부품별 상세 명세다.
Z 높이, 접촉 판정, 소유 관계, 저장, 배선 도구의 공통 규칙은 전체 계획을
따르고, 이 문서는 각 부품의 구동 조건·작용면·신호 의미를 정의한다.
형상은 [최신 디자인 모음](design_assets/new_components_catalog.svg)을 따른다.

표의 포트 ID는 **신규 부품용 논리 ID 제안**이다. 제조사 커넥터의 물리
핀 번호가 아니다. 실제 모델을 선정하면 모델별 매핑을 별도로 작성한다.
기존 부품의 숫자 포트 ID는 보존하고 신규 타입에만 안정적인 ID를 할당한다.
시안의 단자 개수와 색상보다 확정된 기능 명세를 우선하며, 추가 단자가
필요하면 몸체에 부착된 커넥터/단자대를 수정한다.

확정: 실물 중심 형상, 상단의 작은 실린더 단자대, 아래 방향 흡착면,
평면 일체형의 오른쪽 로드, 기본 상태에서 노출되지 않는 스토퍼 축,
높이별 창고 2칸, 통합 배선 도구.
제안: 센서 출력 방식 기본값, 제어 포트 구성, 구동 수치, 고장·정지 정책.
실제 시험 장비와 특정 제조사 모델의 핀 번호·정격은 아직 확정하지 않았다.

## 2. 공통 포트와 신호 규칙

| 연결 타입 | 세부 역할 | 처리 |
| --- | --- | --- |
| 전기 | DC 전원, 센서 출력, 제어 입력 | 기존 전압/전원 기준과 SINK/SOURCE 판정 사용 |
| 전기 | AC 입력, 모터 U/V/W, PE | DC 논리 신호와 구분. PLC 출력으로 모터 상을 직접 구동하지 않음 |
| 전기 | 엔코더, 통신 | 커넥터 단위 묶음 연결. 일반 전원선과 역할 호환 불가 |
| 공압 | 실린더 챔버 A/B | 압력 네트워크로 구동하며 전기 ON/OFF로 대체하지 않음 |
| 공압 | 진공 VAC | 진공 공급 역할. 양압 연결과 구분 |
| 광 | 증폭부 TX/RX, 광 헤드 | 광 역할 쌍을 검사. PLC 전기 입력에 직접 연결하지 않음 |

모든 연결은 한 배선 도구로 만든다. 시작 핀의 연결 타입으로 선 종류를
결정하고, 같은 타입 안에서도 역할·전압·채널 호환을 검증한다.
엔코더/통신 묶음은 전기 타입의 특수 역할이며, 광화이버 감지 케이블과
혼동하지 않는다. 묶음 커넥터는 하나의 가상 24V 디지털 핀이 아니다.

포트 정의에는 ID, 표시 라벨, 연결 타입, 역할, 전압/압력 프로필,
채널 또는 커넥터 규격, 최대 연결 수를 둔다. 색상과 `isInput`만으로
연결 유효성을 판단하지 않는다. 내부 광 링크·서보 링크는 양 끝 ID로
확인하며, 화면상 교차나 겹침은 접속이 아니다.

센서 내장형의 기본 제안은 DC 24V, PNP NO 출력이다. 기존 센서 설정의
PNP/NPN·NO/NC를 재사용할 수 있도록 한다. 전원 단절 때 NC라는 이유로
출력을 활성화하지 않는다. FWD/REV는 전진/후진 **완료 출력**이며
실린더 구동 입력이 아니다. 내부 끝단 검출은 자신의 스트로크를 사용한다.

모든 이동 축은 물리 스텝에서 갱신하고, 렌더가 상태를 바꾸지 않는다.
전원/압력 상실은 별도 상태로 처리한다. 위치를 초기값으로 순간이동시키지
않으며, 상세 관성·누설·중력은 첫 구현에서 생략한다. 정지 유지나 감속은
아래 부품별 제안 정책을 적용한다. 이것은 실물 안전 동작을 보증하는 모델이 아니다.

## 3. 센서 내장 복동 실린더

기존 복동 실린더 이동식을 재사용한다. 별도 목록 항목으로 등록하되
센서 유무 때문에 압력·스트로크 계산을 복제하지 않는다.

| 논리 ID | 라벨 | 타입/역할 | 의미 |
| --- | --- | --- | --- |
| air_a | A | 공압/챔버 | 정방향 챔버 |
| air_b | B | 공압/챔버 | 역방향 챔버 |
| sensor_24v | 24V | 전기/DC 전원 입력 | 내장 센서 전원 |
| sensor_0v | 0V | 전기/DC 공통 | 센서 기준 전위 |
| sensor_fwd | FWD | 전기/센서 출력 | 완전 전진 검출 |
| sensor_rev | REV | 전기/센서 출력 | 완전 후진 검출 |

- A/B 차압, 유효 압력, 유량으로 전진/후진을 계산하고 끝단에서 제한한다.
  A가 전진을 만드는 챔버인지는 기존 실린더 구현을 확인해 같은 규칙으로 고정한다.
- 양쪽 동일 압력 또는 공급 상실은 첫 모델에서 이동 정지/현재 위치 유지로
  제안한다. 센서 전원 상실은 이동 자체를 막지 않고 출력만 비활성화한다.
- 기본 작용 높이는 설치 Z 한 개다. 로드 끝의 XY 영역과 같은 Z의
  자유 공작물만 밀 수 있다. 공작물을 자동 소유하거나 흡착하지 않는다.
- 중간 위치에서는 FWD/REV 모두 OFF. 끝단 허용 오차와 히스테리시스를
  두고 진동을 방지한다. 정상 범위에서 두 완료 신호가 동시에 켜지지 않는다.
- 설정: 스트로크, 초기 위치, 속도/유량 계수, 설치 Z, 센서 출력 방식.
  런타임: 위치, 속도, 챔버 압력, 끝단 상태, 유효 센서 출력.

## 4. 센서 내장 흡착 실린더

복동 실린더에 하향 흡착 헤드가 붙은 별도 부품이다. 헤드 상하 폭은
같고 아래쪽만 두껍게 표현한다. 독립 흡착패드 부품을 추가하지 않는다.

3절의 6개 포트를 그대로 사용하고 다음 포트를 추가한다.

| 논리 ID | 라벨 | 타입/역할 | 의미 |
| --- | --- | --- | --- |
| vacuum | VAC | 공압/진공 입력 | 헤드 진공 공급 |

- XY 이동은 복동 실린더 로드가 담당한다. 흡착 작용은 헤드 아래면의
  접촉 높이에서 수행한다. 헤드 두께 오프셋은 공통 기준점에서 계산한다.
- VAC의 유효 진공도, 실제 접촉 XY, 동일 Z, 자유 공작물이 모두 필요하다.
  양압을 공급했다고 흡착 ON으로 처리하지 않는다.
- 여러 후보가 겹치면 안정적인 대상 선택 규칙으로 한 개만 소유한다.
  기존 소유자가 있는 공작물은 탈취하지 않는다.
- 흡착한 공작물은 헤드 상대 XY와 접촉 Z를 추종한다. 진공 해제/공급
  상실 시 소유를 해제하고 현재 위치에서 창고·박스 인계 가능성을 검사한다.
- FWD/REV는 로드 끝단이며 흡착 성공 신호가 아니다. 진공압 검출 신호가
  필요하면 압력스위치 모델을 별도로 검토한다. 현재 시안에 없는 VAC_OK를
  조용히 추가하지 않는다. UI에서는 흡착 여부를 런타임 상태로 확인할 수 있다.
- 설정: 3절 설정 + 진공 임계값/히스테리시스, 헤드 작용면.
  런타임: 진공도, 흡착 공작물 ID, 상대 위치, 인계 결과.

## 5. 스토퍼 실린더

두 가이드 축이 한 장의 하부 판과 연결된 구조다. 후진 시 축은 몸체 안에
수납되고 판은 몸체 바로 아래에 붙는다. 하강할 때만 축과 판이 노출된다.
입면·평면은 같은 상태를 투영한다.

포트 제안은 A/B + 24V/0V/DOWN/UP의 센서 내장형이다. 사진의 센서
배선을 표현하되 정확한 실물 센서 수는 모델 선정 시 확인한다.

| 논리 ID | 라벨 | 타입/역할 | 의미 |
| --- | --- | --- | --- |
| air_a / air_b | A / B | 공압/챔버 | 하강/상승 구동. 기존 차압 규칙과 방향 매핑 |
| sensor_24v / sensor_0v | 24V / 0V | 전기/DC 전원 | 내장 센서 전원 |
| sensor_down | DOWN | 전기/센서 출력 | 하강 끝단 |
| sensor_up | UP | 전기/센서 출력 | 상승 끝단 |

- 기본 제안: 수납 높이 2, 차단 높이 1. 사용자가 이동 범위를 옮길 수 있다.
- 하부 판의 현재 XY 차단 영역과 Z가 공작물 운반면에 맞으면 진행을 막는다.
  몸체 전체 AABB나 레이어 범위 전체를 차단 영역으로 쓰지 않는다.
- 빠른 이동에서도 공작물이 판을 관통하지 않도록 이전/현재 위치로
  이동 경로를 검사한다. 통과한 공작물을 멀리서 되돌리는 스냅은 하지 않는다.
- 판은 공작물을 정지시키지만 컨베이어 모터 전원을 자동 차단하지 않는다.
  벨트 정지는 PLC가 모터를 제어한다. 차단 유지 중 이송 적용으로 공작물이
  떨리거나 판을 밀고 지나가지 않게 한다.
- UP/DOWN 출력은 자체 끝단 검출이다. 상승 후에는 같은 XY의 공작물이
  통과한다. 정면 기본 상태에 축 선을 남기지 않는다.

## 6. DC 모터

정면 원형 몸체와 출력축으로 표현한다. 가공 실린더 내부 모터를 대체하거나
새 가공 실린더 타입을 만들지 않는다.

| 논리 ID | 라벨 | 타입/역할 | 의미 |
| --- | --- | --- | --- |
| motor_positive | + | 전기/DC 모터 전력 | 모터 단자 |
| motor_negative | − | 전기/DC 모터 전력 | 모터 단자 |

- 단자 사이의 유효 전압으로 방향과 목표 회전속도를 계산한다. +/− 표시는
  기준 극성이며 역극성 전원 지원 여부는 기존 전기 해석기의 표현 범위를 확인한다.
- 시뮬레이터의 단순 모델은 전압 비례 속도와 제한된 가속/감속을 사용한다.
  무전압 시 감속해 정지한다. 전원 신호와 회전속도를 같은 bool로 합치지 않는다.
- 이 모터를 놓기만 했다고 주변 실린더/벨트가 구동되지 않는다. 기계적
  부하 연결은 장착 설정으로 명시해야 하며 전기 배선으로 만들지 않는다.
- 설정: 정격 전압, 기준 속도, 가감속, 부하 장착 대상.
  런타임: 유효 전압, 각도, 속도, 방향, 연결 유효성.

## 7. AC 서보 모터와 서보앰프

### 7.1 실물 규격과 시뮬레이터 프로필

현재 디자인은 AC 서보의 U/V/W/PE 및 엔코더 구조를 기준으로 한다.
4선 A+/A−/B+/B− 구성으로 바꾸지 않는다. 정확한 모델 없이 제조사
커넥터 핀 번호를 확정하지 않는다.

MR-JE-A는 펄스열 위치 지령을 지원한다. 사진의 MR-JE-B 외관을 참고한
것과 MR-JE-A 제어 인터페이스를 그대로 구현하는 것은 구분해야 한다.
근거: [Mitsubishi MR-JE 제어 기능](https://www.mitsubishielectric.com/fa/vn_en/products/drv/servo/pmerit/mr_je/amp/performance.html),
[MR-JE-A 신호·배선 매뉴얼](https://dl.mitsubishielectric.com/dl/fa/document/manual/servo/sh030128/sh030128j.pdf).

첫 구현 제안은 **범용 펄스 지령 AC 서보 프로필**이다. 외관 참고와
제어 프로필을 부품 정보에 표시한다. 특정 MR-JE-B의 핀아웃이라고
표기하지 않는다. 실물 모델을 확정하면 이 프로필과 매핑을 함께 갱신한다.

### 7.2 서보 모터 포트

| 논리 ID | 라벨 | 타입/역할 | 연결 상대 |
| --- | --- | --- | --- |
| motor_u / motor_v / motor_w | U / V / W | 전기/서보 전력 상 | 대응 앰프 출력 상 |
| protective_earth | PE | 전기/보호접지 | PE 네트워크. 0V와 구분 |
| encoder | ENC | 전기/엔코더 묶음 | 호환 앰프 ENC |

출력축 각도/속도와 엔코더 피드백은 같은 실제 축 상태에서 나온다.
모터에 PLC 펄스를 직접 넣어 회전시키지 않는다. 앰프가 지령을 처리하고
유효 전력·피드백 연결이 있는 모터 축을 구동한다. 첫 구현에서는 PWM과
권선 전류 파형을 실제로 적분하지 않고 축 제어를 추상화한다.

### 7.3 서보앰프 포트 제안

| 논리 ID | 라벨 | 타입/역할 | 의미 |
| --- | --- | --- | --- |
| ac_l1 / ac_l2 / ac_l3 | L1 / L2 / L3 | 전기/AC 전력 입력 | 선택한 전원 프로필. 단상 지원은 모델별 설정 |
| protective_earth | PE | 전기/보호접지 | 보호접지 |
| control_24v / control_0v | 24V / 0V | 전기/DC 제어 전원 | 논리 I/O 전원/기준 |
| pulse / pulse_common | PULSE / P-COM | 전기/펄스 지령 | 펄스+방향 프로필의 펄스와 기준 |
| direction | DIR | 전기/방향 입력 | 지령 방향 |
| servo_on | SON | 전기/허가 입력 | 서보 구동 허가 |
| alarm_reset | RESET | 전기/제어 입력 | 원인 제거 후 알람 리셋 |
| ready | READY | 전기/상태 출력 | 구동 준비 완료 |
| in_position | INP | 전기/상태 출력 | 위치 오차/속도가 설정 허용값 이내 |
| alarm | ALARM | 전기/상태 출력 | 시뮬레이터 정의: 고장 시 활성 |
| motor_u / motor_v / motor_w | U / V / W | 전기/서보 전력 출력 | 모터 대응 상 |
| encoder | ENC | 전기/엔코더 묶음 | 모터 피드백 |

이 라벨은 범용 논리 인터페이스 제안이다. 차동 펄스 쌍, 오픈컬렉터 기준,
실물 ALM의 정상/고장 극성은 제조사 프로필에서 지정한다. PULSE/DIR와
CW/CCW 펄스 모드를 동시에 같은 의미로 쓰지 않는다. 시안의 CN/USB
커넥터에 기능을 임의 배정하지 않고 확정 프로필에 맞춰 앵커를 정한다.

- 전원·상 연결·엔코더·SON이 유효해야 READY와 구동이 가능하다.
  설정된 PE 검사 결과는 전원/엔코더 오류와 구분해 표시한다.
- 펄스는 물리 tick의 단순 ON 샘플이 아니라 기존 PLC 고속출력의 누적
  펄스 수/시간 정보를 소비한다. 240Hz보다 빠른 지령을 누락시키지 않는다.
- 전자기어로 누적 펄스를 목표 각도로 변환하고 속도·가속 한계로 추종한다.
  INP는 실제 위치 오차와 속도로 판정하며 지령 수신 즉시 ON 하지 않는다.
- SON 해제는 기본 모델에서 구동 정지/위치 유지로 제안한다. 실제 자유
  회전·중력 낙하·브레이크 동작은 모델별 후속 범위다.
- 피드백 단절·잘못된 상 역할·범위 초과는 원인별 알람과 구동 차단으로
  처리한다. RESET 입력만으로 원인이 남아 있는 알람을 지우지 않는다.
- 앰프의 위치/속도는 HMI 디바이스 매핑으로 확인한다. 숫자 위치를 보내는
  가짜 24V 출력 핀은 만들지 않는다.

## 8. 서보 리프트

볼스크류 액추에이터이며 수직 이동을 평면에서 Z로 표현한다. 모터가
포함된 완성 부품으로 목록에 등록한다. 독립 서보 모터와 중복 장착하지 않는다.
장착된 모터의 축 상태 처리만 7절과 공유한다.

| 논리 ID | 라벨 | 타입/역할 | 의미 |
| --- | --- | --- | --- |
| motor_u / motor_v / motor_w / protective_earth | U / V / W / PE | 전기/모터·접지 | 내장 모터 외부 연결 |
| encoder | ENC | 전기/엔코더 묶음 | 내장 모터 피드백 |

시안의 소수 색상 핀을 단일 MOTOR ON으로 구현하지 않는다. 위 포트는
몸체 부착형 커넥터로 표현한다. 추가 원점/상하한 센서와 브레이크 단자는
필요 시 별도 프로필로 정의하며 존재하지 않는 내장 센서로 가정하지 않는다.

- 모터 각도와 볼스크류 리드/기어비로 캐리지 이동거리를 계산한다.
  이동거리의 정규화 위치를 설정 Z 범위에 매핑한다. mm와 레이어 단위를
  구분하고 HMI는 실제 이동거리 또는 레이어 높이 중 선택한 단위를 표시한다.
- 기본 범위 1~3, 초기 높이 3 제안. 중간 높이에서도 연속 이동 가능하다.
  기계적 끝단에서 clamp하고 초과 지령은 도달 완료 대신 제한 상태로 알린다.
- 리프트 캐리지만으로 주변 공작물을 자동 흡착하지 않는다. 부하/흡착부는
  장착 설정 또는 아래 일체형으로 정의한다.
- 설정: 리드, 기어비, 유효 스트로크, 최대 속도/가속도, 초기 위치, Z 범위.
  런타임: 목표/실제 위치, 속도, 높이, 제한 상태, 연결 앰프 ID.
- 재생성/리셋 때 설정된 초기 위치로 초기화한다. 첫 구현의 원점은 초기
  위치 설정 기준이며 실제 원점복귀 시퀀스 지원으로 표시하지 않는다.

## 9. 리프트·흡착 실린더 일체형

한 배치 부품 안에 8절 리프트와 4절 실린더가 있다. 독립 부품 두 개를
숨겨 생성하지 않는다. 평면에서 로드는 오른쪽으로 뻗고 헤드는 아래를 향한다.

핀아웃은 리프트의 U/V/W/PE/ENC와 실린더의 A/B/VAC/24V/0V/FWD/REV를
모두 외부로 제공한다. ID는 `lift.*`, `cylinder.*`처럼 하위 역할을 구분한다.
센서 단자대의 24V를 서보 AC 입력으로 해석하지 않는다.

- 리프트 위치는 Z, 실린더 스트로크는 로컬 XY를 변경한다.
- 헤드 월드 XY = 부품 XY + 회전/반전된 장착 오프셋·로드 변위.
  헤드 Z = 캐리지 높이 + 설정된 하향 작용면 오프셋.
- 흡착 공작물은 두 축 움직임을 함께 추종한다. 이동 중 창고 다른 단이나
  컨베이어의 영향은 받지 않는다. 허용 범위 전체에 동시에 작용하지 않는다.
- 한 축 공급이 끊겨도 다른 축까지 무조건 초기화하지 않는다. 진공 상실은
  공작물 해제, 서보 구동 상실은 제안 정지 정책, 센서 전원 상실은 출력
  비활성화를 각각 적용한다.
- 정면 확인은 캐리지 높이, 평면은 실제 XY 스트로크를 표시한다.
  표시 변경이 두 축 위치·포트 앵커·공작물 소유를 바꾸지 않는다.

## 10. 6칸 저장창고

수동 구조물이므로 기본 **배선 핀 없음**. 슬롯 점유를 PLC 입력으로
알리는 가상의 핀을 만들지 않는다. 필요하면 실제 별도 센서를 배치한다.

| 기본 높이 | 왼쪽 슬롯 | 오른쪽 슬롯 |
| --- | --- | --- |
| 3 | 5 | 6 |
| 2 | 3 | 4 |
| 1 | 1 | 2 |

- 각 슬롯은 고유 ID, 로컬 XY 수납 영역, 서비스 높이, 최대 1개 점유를 가진다.
- 방출 공작물의 XY와 Z가 맞고 리프트가 정지 허용값 안에 있을 때만 인계한다.
  이미 점유된 슬롯은 덮어쓰지 않는다. 실패 공작물은 현재 위치에 남는다.
- 저장 공작물은 창고 소유 상태로 이송 대상에서 제외한다. 재흡착 시
  실제 헤드 접촉과 진공 조건을 만족하면 슬롯 해제와 소유 이전을 원자적으로 한다.
- 한 높이에 2개, 전체 6개 제한. 범위를 옮겨도 슬롯 ID와 좌우 의미는 유지한다.
- 평면은 두 열, 정면 오버레이는 실제 점유 6칸을 표시한다. 빈 몸체에
  번호/공작물 원을 고정 그림으로 넣지 않는다. 슬롯 번호는 편집 UI에서 확인한다.

## 11. 광화이버 증폭부·송신 헤드·수신 헤드

세 개의 독립 목록 항목이다. 광 포트와 전기 단자는 각각 몸체에 붙인다.
첫 구현은 송신/수신 헤드가 마주보는 투과형 감지 모델을 제안한다.

| 부품 | 논리 ID / 라벨 | 타입/역할 | 의미 |
| --- | --- | --- | --- |
| 증폭부 | power_24v / 24V | 전기/DC 전원 | 증폭부 전원 |
| 증폭부 | power_0v / 0V | 전기/DC 공통 | 전원 기준 |
| 증폭부 | signal / SIG | 전기/센서 출력 | 설정 모드에 따른 검출 출력 |
| 증폭부 | optical_tx / TX | 광/송신 연결 | 송신 헤드 연결 |
| 증폭부 | optical_rx / RX | 광/수신 연결 | 수신 헤드 연결 |
| 송신 헤드 | fiber / TX | 광/송신 헤드 연결 | 증폭부 TX와 연결 |
| 수신 헤드 | fiber / RX | 광/수신 헤드 연결 | 증폭부 RX와 연결 |

- 유효 전원, 양쪽 광 연결, 헤드의 방향/거리/높이 정합성이 필요하다.
  각 헤드는 하나의 증폭부 채널에 연결하며 광 연결을 전원처럼 분기하지 않는다.
- 감지 구간은 두 헤드 사이의 실제 XY 광선과 지정 감지 폭이다. 광 케이블
  경로는 감지 구간이 아니다. 증폭부 설치 Z는 공작물 감지 높이가 아니다.
- 첫 구현은 두 헤드가 같은 Z인 수평 광선만 지원한다. 서로 다른 헤드 Z는
  정렬 오류로 표시하며 3D 경사 광선을 억지로 XY 광선으로 해석하지 않는다.
- 같은 높이 공작물이 광선을 차단하면 수광 상태가 변한다. 재질에 따른
  수광량은 단순 설정 모델로 제한하고, 금속/비금속 분류를 자동 내장하지 않는다.
- SIG 기본 제안은 PNP NO, 차광 시 검출 활성이다. Light-ON/Dark-ON과
  NO/NC의 관계를 명시적 설정으로 관리한다. 정렬/연결 오류는 정상 공작물
  검출과 구분해 UI에 표시한다. 출력은 선택 모드에 따라 해석한다.
- 표시창의 수광량은 모델 계산값이며 실제 제조사 단위라고 표기하지 않는다.
  SET/MODE는 설정 명령으로 처리하며 렌더에서 변경하지 않는다.

## 12. 터치패널

패널은 전기 표시/조작 장치이며 XY/Z 접촉 효과나 공작물 소유가 없다.

| 논리 ID | 라벨 | 타입/역할 | 의미 |
| --- | --- | --- | --- |
| power_24v / power_0v | 24V / 0V | 전기/DC 전원 | 패널 전원 |
| communication | COM | 전기/통신 묶음 | 호환 PLC 통신 포트와 연결 |

COM은 공통 0V가 아니라 통신 커넥터다. PLC 디바이스 주소 읽기/쓰기를
연결 프로필로 제공한다. 실제 RS-232/RS-485/Ethernet 핀 번호는 선택한
모델에 따라 다르므로 범용 COM 하나를 특정 표준 핀아웃으로 표기하지 않는다.

- 전원과 유효 PLC 링크가 있을 때만 디바이스를 읽고 조작 명령을 보낸다.
- 버튼은 순간/유지형 설정과 대응 PLC 비트를 사용한다. 패널 버튼으로
  실린더 위치나 모터 내부 상태를 직접 변경하지 않는다.
- 전원/통신 단절 시 오프라인을 표시하고 입력을 차단한다. 표시값은 무효
  또는 마지막 값임을 구분한다. 서보 실제 위치는 매핑된 레지스터에서 읽는다.

## 13. 기존 가공 실린더 확장 경계

신규 타입은 아니지만 새 부품과의 연동 검증에 포함한다. 현행 숫자 포트
ID는 0=24V, 1=FWD, 2=REV, 3=MOTOR_CTRL, 4=0V, 5=A, 6=B다.
이 ID를 신규 센서 내장형의 표 순서로 재배열하지 않는다.

기존 전기/공압 구동과 내장 모터를 재사용한다. FWD/REV의 선언 방향은
현행 코드에서 입력 플래그로 되어 있으므로 실제 해석을 검증해 센서 출력
역할을 정리한다. 포트 ID를 유지한 채 역할 메타데이터를 보완한다.

상승 2/하강 1 기본 범위에서 가공 헤드의 실제 접촉 높이를 계산한다.
같은 높이의 XY 접촉, 모터 동작, 기존 가공 시간 조건을 만족할 때만
가공한다. 상승 상태에서 주변 공작물을 끌어당기거나 고정하지 않는다.

## 14. 구현 계약과 검증

부품 정의는 포트·초기 설정·렌더를 제공하고, 리졸버는 연결의 유효 전기/
공압/광 상태를 계산한다. 액추에이터가 축 상태를 갱신한 뒤 공통 물리
판정이 공작물 효과를 적용한다. UI는 검증된 명령만 전달한다.
센서 출력과 HMI 표시가 읽는 실제 상태를 별도 복제하지 않는다.

필수 검증은 다음과 같다.

- A/B 배선 → 압력 → 스트로크 → 전원 있는 FWD/REV → PLC 입력.
- A/B와 VAC 독립, 양압 흡착 금지, 공급 단절과 소유 이전의 일관성.
- 스토퍼 수납 시 축 미노출/통과, 하강 시 차단, 모터 제어 독립.
- PLC 누적 펄스 → 앰프 → 모터/엔코더 → 리프트 실제 높이 → INP.
- 상·엔코더·전원 역할 오류 시 READY/알람/구동 결과 검증.
- 일체형 XY/Z 독립 및 흡착 공작물 추종, 단절 원인별 상태 검증.
- 창고 3번→2번 적재와 재취출, 중복 점유 방지, 높이가 다른 슬롯 분리.
- 광 링크·정렬·Z·차광·출력 모드와 PLC 감지 결과 검증.
- HMI 전원/통신과 명령·디바이스 매핑, 오프라인 처리 검증.
- 모든 포트는 통합 배선 도구에서 양쪽 시작 방향으로 연결 검증.
  정면 확인/Undo/저장 복원 후에도 포트 ID와 역할 의미가 유지됨.

## 15. 구현 착수 시 확정할 프로필

범용 모델로 진행할 수 있는 부분은 위 제안대로 계획하되 다음 사양은
구현 전에 확인하고 명세를 갱신한다.

1. 서보앰프 실물 모델, 펄스 방식/전압, 전원 구성, 실제 커넥터 매핑.
2. 리프트 리드/스트로크/기어비와 실제 원점·리미트·브레이크 유무.
3. 실린더·스토퍼 센서 방식, 압력/속도 기준, VAC 공급 장치의 기존 지원 여부.
4. 광화이버 검출 모드/출력 방식과 감지 거리 기본값.
5. HMI 통신 프로필 및 기존 PLC 통신 포트/디바이스 연결 지점.

신규 커넥터 역할을 지원하려면 기존 전기 네트워크의 DC 신호 해석과
서보/통신 링크를 분리해야 한다. 포트만 추가하고 연결된 모든 전기선을
같은 24V 네트워크로 해석하는 구현은 완료로 보지 않는다.
