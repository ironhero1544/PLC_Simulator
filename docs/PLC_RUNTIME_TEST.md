# PLC 스캔 실행 검증

2026-10-01: CSV 및 GX Works2 가져오기 없이 앱과 같은
`CompiledPLCExecutor`에 프로그램을 로드하여 `ExecuteScanCycle`을 실행했다.
`ladder_rewrite_tests --runtime-only` 또는 CTest `ladder_runtime`으로 재현한다.

## 생산 순서 통합 시나리오

시작 버튼 → 자기유지 → 200ms 지연 → 모터 출력 → 센서 3회 카운트 →
모터 정지 순서를 50회 반복했다. 센서 입력은 각 제품마다 5스캔 유지했다.
1,115스캔에서 누적 150개, 카운터의 상승 에지 동작, 지연 이전 출력 OFF,
완료 스캔의 출력 OFF, 타이머 초기화를 확인했다. 별도 정지 입력은 즉시
자기유지와 출력을 해제하며 정지 해제만으로 재시작하지 않았다.

## 연산 통합 시나리오

121스캔, 입력 상승 에지 20회에서 ADDP 결과 D0=20,
DADDP 결과 D2/D3=4,100,000을 확인했다. 매 상승 에지 뒤 입력을 5스캔
유지해 펄스 명령의 중복 실행도 검사했다. DEMOV/DEADD의 1.5+2.25를
INT로 변환한 결과는 3, DECMP의 작은 값 출력은 M12만 ON이다.
$MOV의 문자열 AB는 D100=0x4241, D101=0으로 저장됐다.

## 추가 실행 시나리오

기존 타이머·카운터 활성화/유지/초기화, 가상 축의 유한 펄스 생성·가감속·
상대/절대 이동·완료 상태, 가상 인버터 명령, MODBUS 슬레이브 메모리,
CF 파일 생성/저장/읽기/전원 차단 관련 실행 검사를 함께 통과했다.
각 검사는 실행 결과와 메모리·장치 상태를 확인한다.

시간은 `SetContinuousExecution`의 고정 스캔 간격으로 재현한다.
이번 결과는 에뮬레이터 실행기와 가상 장치 검증이며 GUI 입력 연결,
실제 PLC CPU/물리 통신/실제 모터 동작 검증은 포함하지 않는다.
모든 FX 명령·피연산자 조합을 전수 실행했다는 의미도 아니다.
