# DC 모터 전압 제어 드라이버 (2026-10-05)

기준: [부품 물리 동작·핀아웃](WIRING_NEW_COMPONENT_SPEC.md),
[구현 범위](WIRING_IMPLEMENTATION_SCOPE.md).

## 부품 목록

`자동화설비산업기사` 필터는 자동화 공통 부품과 신규 자격증 부품을 표시하며
링 센서와 RTL 모듈은 제외한다. 기존 전체/자동화/반도체 필터는 유지한다.
필터는 별도 행으로 배치해 긴 자격증 이름과 오른쪽 버튼이 겹치지 않는다.
Z 레이어 창의 화살표 버튼을 `Z` 버튼으로 바꾼다.

## 외형과 모델

검은 판형 본체, 상단 몸체에 붙은 단자대, 하단 방열판 구조를 첨부 사진에서 참고한다.
기존 부품과 같은 평면 도형·회색 본체·원형 핀·줌에 비례하는 글자를 사용한다.
사진은 BLDC용 U/V/W·홀 센서 드라이버지만 기존 DC 모터는 2선식이다.
따라서 추가 부품은 해당 제품의 복제 모델이 아닌 **24V 2선식 DC 드라이버**이며
M+/M- 출력으로 기존 모터를 연결한다. BLDC/홀 센서/상 전환 모델은 포함하지 않는다.
전압 지령으로 속도를 조절하는 실물 프로필 참고:
[제조사 드라이버 자료](https://www.promoco-motors.com/products/BLDC/drivers/BLDC-5015%20Series.pdf).

## PLC PWM 제어

PLC의 PWM 출력으로 속도를 제어하므로 아날로그 출력 모듈은 필요하지 않다.
가변저항이나 드라이버 수동 전압 설정도 사용하지 않는다.
드라이버는 배선된 Y0~Y3의 PWM 듀티와 EN/DIR/BRK 신호를 받아 모터에 전력을 공급한다.
고정 듀티에서 PWM 주파수만 바꾸어도 목표 속도는 바뀌지 않는다.
PLSY 등 펄스 개수/주파수 명령은 PWM 속도 지령으로 변환하지 않는다.

## 핀아웃

| ID | 라벨 | 방향 | 역할 |
| --- | --- | --- | --- |
| 0 | 24V | 입력 | 모터 주 전원 |
| 1 | 0V | 입력 | 전원·신호 기준 |
| 2 | EN | 입력 | PLC 운전 허용 |
| 3 | DIR | 입력 | PLC 정회전/역회전 선택 |
| 4 | BRK | 입력 | PLC 정지 지령 |
| 5 | PWM | 입력 | PLC Y0~Y3의 PWM 듀티 지령 |
| 7 | M+ | 출력 | DC 모터 + 단자 |
| 8 | M- | 출력 | DC 모터 - 단자 |

기존 M+/M- 포트 ID는 유지한다. 이전 AVI 단자는 PWM 역할로 변경한다.
PWM에는 PLC Y0~Y3만 연결할 수 있으며 단일 연결로 제한한다.
EN/DIR/BRK의 활성 전압은 PLC 출력 모드와 일치한다.
SOURCE 출력은 24V 활성, SINK 출력은 0V 활성이다. 개방 입력은 비활성이다.

운전 허용 중 PWM 배선이 없거나 잘못되면 오류와 함께 정지한다.
PLC 정지, PWM 듀티 0%, EN 해제 또는 BRK 활성은 모터 정지 지령이다.
전원 상실도 정지하며 수동 설정으로 대신 운전하는 경로는 없다.
주 전원 유효 범위는 22~26V, 0V 단자의 유효 기준은 0~2V다.
M+/M-는 대응 모터 단자에만 연결되며 각 출력은 단일 배선이다.

## 래더·배선 예

- `Y0 → PWM`, `Y4 → EN`, `Y5 → DIR`, `Y6 → BRK`.
- 전원 `24V → 드라이버 24V`, `0V → 드라이버 0V`.
- 드라이버 `M+ → 모터 +`, `M- → 모터 -`.

```text
LD M100
PWM D200 D201 Y0
LD M100
OUT Y4
LD M101
OUT Y5
LD M102
OUT Y6
END
```

D200은 ON 시간(ms), D201은 주기(ms)다. 래더의 MOV 명령으로 설정한다.
예: D200=10, D201=20이면 50% 듀티이고 목표 속도는 모터 최대 속도의 절반이다.
D200=5로 변경하면 같은 주기에서 25% 속도다. D200=10, D201=40도 듀티가
25%이므로 목표 속도는 같다. ON 시간은 0~주기, 주기는 1~32767ms를 허용한다.
실행 중 D 값 변경도 PWM 듀티/주파수에 반영하며 잘못된 값은 PWM 축을 정지시킨다.

## 시뮬레이션 모델

실행기에서 실제 PWM ON 시간/주기를 읽어 듀티를 전달한다.
프레임에서 관찰한 Y의 순간 ON/OFF만으로 속도를 정하지 않아 샘플링 오차를 피한다.
모터 평균 전압은 주 전원 모델 24V × 듀티이며 목표 속도도 듀티에 비례한다.
DIR에 따라 M+/M-의 전압 극성을 바꾸는 H-브리지 동작을 모사한다.
PWM 파형의 전류·부하 토크는 별도로 해석하지 않고 기존 DC 모터의 가감속을 재사용한다.
PWM 명령 없는 일반 Y ON/OFF 출력은 듀티 100%/0%의 단순 제어로 사용할 수 있다.
배선된 PLC가 실행 중일 때만 속도 지령을 전달한다.

## 저장 호환

드라이버와 PWM 배선은 기존 장면 저장과 Undo에 포함한다.
이전 dc_drive_voltage 설정은 읽지 않으며 수동 속도 제어 UI는 제거한다.
이전 전원/아날로그 단자에 연결했던 PWM 포트 배선은 역할 검증에서 제외한다.
