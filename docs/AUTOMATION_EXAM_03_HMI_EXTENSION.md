# 공개문제 3번 실습을 위한 HMI 보완

사용자 승인: 필요한 기능을 보완하고 공개문제 3번 전체를 풀이한다.

## 변경 범위

- 기존 4:3 화면과 최대 32개 위젯 제한을 유지한다.
- 화면을 최대 8개까지 추가하고 이름을 편집할 수 있다.
- 각 위젯은 하나의 화면에 속한다. 현재 화면의 위젯만 표시·조작한다.
- 버튼은 기존 M 비트 제어 또는 화면 전환을 선택한다.
- 화면 전환은 누르고 있던 모든 순간 버튼을 해제한다.
- 상태 메시지는 D 워드 값 0/1/2에 대응하는 세 문구를 설정한다.
  범위 밖 값 또는 통신 불가 상태에서는 `---`를 표시한다.
- 위젯에 표시 조건 비트(M/X/Y)를 지정할 수 있다. 빈칸이면 항상 표시한다.
  단속 운전의 적재 수치 숨김에 사용한다. 숨겨지는 순간 버튼의 눌림도 해제한다.
- 저장 파일에는 화면 이름, 위젯의 화면, 전환 대상, 메시지를 저장한다.
  이전 파일은 기본 화면 하나로 읽는다. 실행 중 화면 번호는 저장하지 않는다.

## 3번에 적용할 화면

| 화면 | 위젯 및 신호 |
|---|---|
| 테스트 동작 | 창고 전진/후진, 가공모터 5초, JOG 상승/하강, 저속/중속/고속, 속도 수치, 원점 램프, 원점 복귀, 시운전 화면 전환 |
| 장비 시운전 | 단속/연속/종료/일시정지, 동작상태 메시지, 금속 적재 수치, 연속 램프, 서보 동작 램프, 테스트 화면 전환 |

속도 선택은 M 버튼을 받은 래더가 500/1000/1500을 D 워드에 MOV하는 방식으로
처리한다. HMI에서 동작 시퀀스를 직접 실행하지 않고 PLC 래더가 제어한다.

## 검증

런타임 회귀 테스트에 두 화면 전환, 숨겨진 버튼 조작 거부, 기존 눌림 비트
해제, 실제 D 값 수신, 저장/로드, 잘못된 화면 대상 거부를 추가했다.
빌드·테스트 결과 및 실제 GUI 확인은 전체 실습 가이드에 이어서 기록한다.
