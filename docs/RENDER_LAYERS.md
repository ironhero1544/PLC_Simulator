# 실배선 표시 레이어

부품 목록의 **Z 바로 오른쪽 L** 버튼으로 표시 레이어 창을 연다.
창은 이동하거나 크기를 조절할 수 있다. 시뮬레이션 중에도 편집할 수 있다.

Z레이어는 물리 높이이며 L 창은 화면에 그리는 순서와 표시 상태를 관리한다.
표시 순서, 그룹, 불투명도와 숨김은 충돌, 센서 감지, 공압 및 전기 연결에
영향을 주지 않는다. 숨긴 부품의 배선도 기존 연결을 유지한다.

## 여러 부품 선택

- 캔버스에서 선택 도구로 빈 공간부터 사각형을 드래그하면 여러 부품을 선택한다.
  선택된 부품을 L 창에서 함께 편집할 수 있다.
- 목록의 부품을 클릭해 선택하고 Ctrl을 누르면 선택을 추가하거나 해제한다.
  Shift를 누르면 마지막 선택부터 클릭한 항목까지 범위를 선택한다.
- 목록 왼쪽의 작은 선택 칸을 누른 채 위아래로 드래그하면 여러 행을 선택한다.
  Ctrl을 누른 채 시작하면 이전 선택도 유지한다.
- 그룹 제목을 누르면 해당 그룹의 모든 부품을 선택한다.

## 순서, 투명도와 숨김

목록은 앞쪽에 그리는 부품부터 표시한다. 각 행에는 부품 ID, 이름,
표시 순서, 불투명도와 그룹 이름이 표시되며 숨긴 행은 ‘숨김’으로 표시된다.

‘위로 / 아래로’는 선택된 부품을 한 단계 옮기고 ‘맨 앞으로 / 맨 뒤로’는
전체 부품의 앞이나 뒤로 옮긴다. 선택한 여러 부품의 내부 순서는 유지한다.
부품 행을 다른 행 위에 드래그해 놓으면 선택 전체가 대상 바로 앞으로 이동한다.

‘불투명도’ 슬라이더는 선택한 모든 부품에 적용된다. 100%는 불투명,
0%는 완전 투명이다. ‘숨기기 / 보이기’는 선택 전체에 적용되며 숨긴 부품과
불투명도가 0%인 부품은 캔버스에서 클릭되지 않는다. L 목록에서 다시 선택해
보이게 하거나 불투명도를 올릴 수 있다. 배선 자체는 표시를 유지한다.

## 그룹

여러 부품을 선택하고 그룹 이름을 입력한 뒤 ‘선택 그룹화 / 이름 변경’을
누른다. 같은 이름을 쓰면 기존 그룹에 합쳐진다. 그룹화 자체는 표시 순서를
바꾸지 않는다. 순서는 각 부품의 숫자와 목록의 부품 행 순서로 확인한다.

선택한 행들을 그룹 제목으로 드래그하면 해당 그룹에 들어간다.
그룹 제목을 드래그하면 그 그룹 전체를 옮긴다. 그룹 제목을 클릭한 뒤
투명도, 숨김이나 순서 버튼을 누르면 그룹 전체를 편집한다.
‘그룹 해제’는 선택한 부품만 그룹에서 뺀다.

그룹은 표시 편집용 묶음이다. 물리적 결합이나 동작 축을 만들지 않는다.

## 저장 및 복구

표시 설정은 프로젝트 레이아웃의 `render_layer`에 저장한다.
`opacity`, `hidden`, `group`을 보관하며 기존 `z_order`가 표시 순서를 유지한다.
이 항목이 없는 이전 프로젝트는 불투명도 100%, 보임, 그룹 없음으로 불러온다.
표시 편집은 기존 배선 편집의 실행 취소 및 다시 실행 대상이다.

일부 공작물과 가공실린더 헤드를 마지막에 다시 그리던 코드는 제거하여
부품 본체 전체가 지정된 표시 순서를 따른다. 이름표와 창고 슬롯 미리보기는
읽기 위한 오버레이로 유지하며 소유 부품의 투명도와 숨김을 따른다.

`examples/automation-exam-03-horizontal.plcproj`와 현재 정답 및 연속운전
JSON 예제는 다음 8개 표시 그룹을 사용한다. 기존 위치, 표시 순서와 동작은
유지하며 모든 부품은 보임, 불투명도 100%이다.

- 제어 · 전원
- 공압 공급
- 공작물 공급
- 송출 · 가공
- 컨베이어 · 분류 · 스토퍼
- 리프트 · 흡착
- 창고 · 저장박스
- 공작물

각 동작부의 솔레노이드와 관련 센서는 해당 동작부 그룹에 포함한다.
예제 생성기도 같은 그룹 구성을 자동으로 적용한다.
