# 2.0 사용자 피드백 반영 (2026-10-06)

## 조사 결과와 적용

- GX Works2에서 말하는 커서는 마우스 포인터가 아니라 래더의 선택칸이다.
  공식 매뉴얼 6.1.2절(6-3쪽)은 읽기/모니터링 모드에서 진한 파란색으로
  표시한다고 명시한다. 선택 테두리를 진한 파란색으로 변경하고 화면 배율에
  따라 두께를 조절한다. 접점 ON 상태의 하늘색 배경은 계속 구분된다.
  END 선택칸에도 같은 색을 적용한다.
- 기존 단동/복동 솔레노이드는 5/2 동작을 구현한다. Festo의 5/2 밸브
  회로 기호를 참고해 본체에 두 위치, 공급/배기 유로, 차단, 다섯 포트,
  솔레노이드와 복귀 방식을 표시한다. 단동은 스프링 복귀, 복동은 양쪽
  솔레노이드다. 내부 배기구는 기존처럼 대기로 처리하며 배선 포트를
  새로 추가하지 않는다. 기존 크기와 연결 위치를 유지한다.
- 자격증 필터와 독립적인 기능 필터를 추가한다. 두 필터를 동시에
  만족하는 부품을 아이콘/이름 보기 모두에서 보여준다.

| 기능 | 포함 부품 |
| --- | --- |
| 입력 | 버튼, 비상정지, 리미트, 일반/유도형/링/광화이버 센서 |
| 출력 | 표시등, 컨베이어, DC/서보 모터, 서보 리프트 |
| 공압 | FRL, 매니폴드, 유량조절, 솔레노이드, 각종 실린더, 진공발생기, 리프트·흡착 일체형 |
| 전원 | DC 전원공급기, AC 전원 |
| 제어 | PLC, HMI, DC 모터 드라이버, 서보앰프, RTL 제어 모듈 |
| 기타 | 저장창고, 박스, 공작물 |

복합 부품은 대표 기능으로 분류한다. 센서 내장 실린더와 리프트·흡착
일체형은 공압에 포함한다. RTL 모듈은 기존 자격증 필터의 허용 범위를
유지하면서 기능 필터에서는 전체/제어에만 표시한다.
