# 공개문제 3번 답안 I/O·HMI·시퀀스

시험 구성도의 미사용 배출실린더 입력은 제외하고, 모델의 16점 입력에 맞춰
이번 답안에서 사용하는 센서를 다시 할당한다. 아래 주소는 원본 시험장의
단자 주소와 동일하다는 뜻이 아니다. 실제 배선 JSON과 CSV가 함께 제공된다.

| 입력 | 역할 | 입력 | 역할 |
|---|---|---|---|
| X0 | 공급 전진 | X1 | 공급 후진 |
| X2 | 송출 전진 | X3 | 송출 후진 |
| X4 | 가공 하강 | X5 | 가공 상승 |
| X6 | 스토퍼 하강 | X7 | 공급 공작물 광 센서 |
| X10 | 흡착실린더 전진 | X11 | 흡착실린더 후진 |
| X12 | 창고실린더 전진 | X13 | 창고실린더 후진 |
| X14 | 재질 판별 위치 광 센서 | X15 | 금속 유도형 센서 |
| X16 | 스토퍼 위치 광 센서 | X17 | 서보앰프 INP |

| 출력 | 역할 | 출력 | 역할 |
|---|---|---|---|
| Y0 | 서보 펄스 | Y4 | 서보 방향 |
| Y1 | 공급 전진 | Y2 | 송출 전진 |
| Y3 | 가공 모터 | Y5 | 가공 하강 |
| Y6 | 가공 상승 | Y7 | 컨베이어 |
| Y10 | 스토퍼 하강 | Y11 | 스토퍼 상승 |
| Y12 | 흡착실린더 전진 | Y13 | 흡착실린더 후진 |
| Y14 | 진공 발생 밸브 | Y15 | 창고실린더 전진 |
| Y16 | 창고실린더 후진 | Y17 | 운전 공압 공급·서보 SON |

일시정지 때 공압 공급 밸브와 SON을 차단한다. 5포트 복솔레노이드가
마지막 전환 상태를 유지하므로 코일 출력만 끄는 것으로 실린더를 정지시키지 않는다.
진공 발생기는 공급 차단 밸브의 앞에서 공압을 받으며, 흡착 중 일시정지에서는
진공을 유지해 공작물이 떨어지지 않도록 한다.
5초 후 초기화 단계에서 공급·송출·흡착·창고를 후진시키고 가공·스토퍼를
올린 뒤 서보 원점으로 복귀한다.

## HMI

테스트 화면: M100 창고 전진, M101 후진, M102 원점 복귀,
M103 가공모터 5초, M104 JOG 상승, M105 하강,
M106/M107/M108 저속/중속/고속. D100=500/1000/1500mm/min.

시운전 화면: M110 단속, M111 연속, M112 종료, M113 일시정지.
D101 금속 적재 수치, D103 상태 메시지(0 정지/1 연속/2 일시정지).
M210이 켜져야 적재 수치를 표시한다. 단속 운전에서는 숨긴다.
화면 전환 버튼은 PLC 비트를 쓰지 않는다.

## 공정 단계

| D10 | 단계 |
|---|---|
| 0 | 대기·공작물 투입 확인 |
| 1→2 | 공급 전진→후진 |
| 3→4→5 | 가공 모터·하강→3초 가공→상승 |
| 6→7 | 송출 전진→후진 |
| 8→9 | 컨베이어·재질 위치 감지→금속 판별 |
| 10→11→12 | 스토퍼 하강·정위치→리프트 하강→진공 ON |
| 13→14 | 창고실린더로 열 선택→리프트로 층 선택 |
| 15→16→17 | 흡착실린더 전진→진공 OFF→후진 |
| 18→19→20 | 리프트 원점→스토퍼 상승→사이클 종료 |
| 30→31 | 비금속 저장박스로 이송→사이클 종료 |

컨베이어·공급·송출·공작물의 이송 높이는 Z1이다.
창고는 Z2/Z3/Z4 세 층이며 각 층에 두 칸이 있다. 리프트는 흡착 위치
Z1과 창고의 세 층을 오간다. 창고 최하단을 Z1에 두면 지나가는 비금속이
창고에 적재되므로 이송 경로와 저장 높이를 분리한다.

금속 1개째: 창고 후진·Z2에서 2번 슬롯.
금속 2개째: 창고 전진·Z4에서 5번 슬롯.
서보 원점 기준 흡착 위치 -6000펄스, 2번 적재 -4000펄스,
5번 적재 및 원점 0펄스다. 60펄스/회전·리드 1mm·스트로크 100mm를 사용한다.
연속 종료 요청은 현재 사이클 종료 후 처리한다.

서보 단계 완료는 펄스 명령의 BUSY(M8340)가 꺼지고 앰프 INP(X17)가 켜진
경우로 판단한다. INP만으로 다음 단계에 진입하지 않는다.

최종 배포 파일은 `automation-exam-03-horizontal.plcproj`와 `answer`/`continuous` 파일이다.
중복된 `-wip` 파일과 오래된 프로젝트는 제거했으며 자동 검증도 최종 파일을 사용한다.
작성 스크립트는 부품 설정·배선·HMI·PLC 소스만 생성한다.
센서 X/Y 값을 주입하거나 공작물의 실행 중 위치·저장 결과를 미리 지정하지 않는다.
실제 GUI 검증 결과는 [실습 가이드](AUTOMATION_EXAM_03_GUIDE.md)에 별도로 기록한다.

## 실습 모델과 시험장 차이

이 답안은 16점 입력·16점 출력 모델을 사용하므로 원본 단자표를 재할당했다.
스토퍼 상승 확인 입력 대신 1.5초 상승 대기를 사용한다. 실제 시험장에서는
제공 장치의 단자표와 상승 센서에 맞춰 주소·완료 조건을 변경해야 한다.
리프트 범위는 흡착 높이 Z1과 세 저장층 Z2~Z4를 포함하는 네 높이다.
Z 범위는 물리 장치의 단순 회전 표시와 별개이며 프로젝트별로 설정한다.
비금속 이송 완료는 16초 이송 타이머로 판단하며 저장박스의 물리 저장은
실제 공작물 도착으로 검증한다. 중간 공급 부품은 사용자가 한 개씩 투입한다.
